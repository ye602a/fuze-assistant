符择 Fuze 开发入口

最新安装、授权、更新、构建与验证说明见 README.md。
源码来源和第三方归属见 THANKS.md；内部包名和进程名保留 aramgg_client 以兼容原有运行组件。

主要入口：
- src/renderer/components/Display.vue：实际运行状态、偏好和战绩入口。
- src/renderer/components/UpdatePanel.vue：个人 GitHub 更新频道。
- src/main/app-update-service.ts：本机加密授权、检查/下载/显式安装、对局限制。
- src/main/capture-stream.ts、screenshot.ts：持续原始帧和位图回退。
- src/main/ocr-worker-client.ts、ocr-worker.ts：独立进程、GPU 预热和 CPU 回退。
- src/main/augment-level-gate.ts、live-level-reader.ts：只读等级、保守调度与超时回退。
- src/main/services/recognition-data-service.ts：识别字典与版本参考的独立缓存。
- src/main/data-loader.ts：单一胜率主源、本地优先。
- src/main/modules/window-manager.ts：窗口生命周期、自适应布局和 renderer-ready 握手。

禁止把运行日志、配置、游戏认证信息或 GitHub token 提交到仓库。
截图与 OCR 自动化验证使用已提交的匿名固定样本；真实国服对局仍需玩家自行进入测试。
