# 原生 UI 信息层级整理

2026-10-18。范围：现有 Slint 主窗口和英雄详情、Direct2D 三卡。保留蓝金配色、侧栏、大状态区、四模块、三个有序卡位，以及五人阵容和候选网格。

## 阅读顺序

- 三卡：图标和名称 → 整体胜率 / 选取率 → 卡片底部推荐度。数值右对齐，进度条紧随其下；四阶段统计、样本和来源放入点击后的说明。推荐度不是胜率，自动排序仍使用整体统计。
- 首页：减少重复标语、版本标签和空卡装饰；资源开销、等级调度与数据来源按需展开。
- 设置：常用设置 / 数据与更新 / 帮助与反馈。偏好先于维护，公开反馈单独展开。
- 战绩：先看结果；旧记录导入和未绑定观察收纳到战绩管理。空结果不显示分页，保留筛选以便清除条件。
- 英雄详情：说明面板位于底部反馈之上，空结果不保留空列表；键盘和鼠标都可展开及收起，Escape 关闭说明。

## 清理记录

移除普通页面的领取轮次研究面板、字段对比、公开样例预览、固定语言占位行、旧更新令牌按钮。显式离线命令和研究服务仍供诊断与回归使用；没有把它们接回玩家页面。

安装入口仅在存在可安装版本时显示；英雄装备动作仅在本人英雄资料可用且场景允许时显示。保留暂停、GPU/CPU 选择、局内资料、更新、缓存、导入、日志和授权反馈等实际功能。未改变推荐、截图、OCR 或 LCU 行为。

## 可复现检查

- `--review-native software` 与 `--review-native skia-software`：宽窄主窗口、状态和设置分组。
- `--review-controls`：两个窗口尺寸下的控件命中、键盘动作、确认和取消；开发入口缺席。
- `--review-direct`：96/120/144/168/192 DPI，完整、部分识别、长名称和缺少统计。
- `--review-host`：隔离服务回调、真实数据模型与原生截图，使用合成数据。
- CI 仅保存明确列出的合成 PNG，七天保留；不上传二进制、账号、日志或玩家截图。

原生窗口采用 Slint 和 DirectWrite；网页 DOM 检测不适用。渲染检查不代表真实游戏、输入法、混合 DPI 或辅助技术已经人工验收。
