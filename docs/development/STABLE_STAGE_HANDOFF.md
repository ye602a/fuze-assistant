# 0.6.3 阶段交接与未完成项

此文件供调整下一阶段路线使用；不把旧归档中的 TODO 当作当前承诺。

### 0.6.3 发布后的界面收尾

- 推荐数据卡片同时展示可用状态、实际数据版本与数据补丁，不再要求展开详情才能找版本。
- 选人区以蓝色五人阵容和金色公共备选区分已选/可选；备选按胜率平铺，保留缺失胜率的英雄并排在末尾。英雄详情宽度调整为 420，常规 10 名备选无需分页或内部滚动。
- 隔离布局验证覆盖三种语言、五种状态及五人阵容加 10 名备选，给标题栏和底部按钮预留空间；不代表实战截图验收。日常小改只复用相关刷新/状态回归，不重复完整 OCR 和差分基准。
- 差分更新不是待实现项：0.6.2 缓存到已发布 0.6.3 的独立重建验证下载 7,065,707 字节，整包 153,411,701 字节，节省约 95.4%；已验证重建文件，不代表本机已安装。
- 以下表格中的实际领取轮次、新版实战延迟、其他电脑自动发现仍是证据待验证项，不以界面修改代替验收，也不自动开启阶段排序。

| 项目 | 当前边界 | 下一阶段是否继续 |
| --- | --- | --- |
| 本地识别、GPU/CPU 回退、等级节流 | 已实现；0.6.3 修复语言查询等待和对局内模型回收，仍需新版实战对照 | 优先收集真实延迟与错误，避免无证据加频率 |
| 自动目录发现 | 进程优先、有限安装信息回退、手动最终回退；本机回退验证成功 | 其他电脑的安装与访问限制仍需验证 |
| 缺失卡位 | 已确认界面且至少两张可信时显示缺失位置；一张或全部遮挡仍不足以可靠建立新推荐 | 若有真实样本再扩展，不猜 ID |

| 日志和诊断 | 保留脱敏计数、耗时；没有自动上传原始日志或截图 | 当前隐私边界继续保持 |

## 验证节奏

日常小改动优先静态检查和与风险对应的少量回归；不为样式或文案重复跑全套。功能阶段收尾统一执行 lint、类型检查、单测、构建及相关 OCR/更新回归。发布仍必须通过 Windows 打包、凭据扫描和真实安装包窗口启动检查。

0.6.3 不代表实际领取语义已经可靠，也不代表修复后的对局延迟已实测达标。这些边界应随稳定测试版一起交接，而不是隐藏在界面中。
