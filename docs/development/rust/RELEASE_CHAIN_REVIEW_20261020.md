## 冗余与兼容复核

PR #112 已删除 74 个确认没有生产入口的文件与 6 个独占开发依赖；旧生产入口可达的
146 个模块集合保持不变，依据见 [清理审计](POST109_VALIDATION_CLEANUP.md)。
本轮在清理后的 master 上逐条检查上表调用关系。便携入口复用已有依赖引导，删除原来的
直接启动模板；新依赖门禁复用已有散列、版本指针和回退实现，没有再造下载 / 安装协议，
没有新增 Cargo 或 npm 依赖，也不把 ZIP-only helper 塞进旧 FUZ 白名单。

保留 Electron 稳定源码作迁移对照、历史日志枚举 / 旧设置兼容、Win32 / 软件渲染诊断入口、
离线 OCR / 更新工具和资源许可。不能因为名字含 legacy、lab、probe 或当前不在主界面显示
就删除。UI 数据语言、运行日志历史字段和取消的多语言 UI 要分别判断，不能混为新增迁移待办。
静态引用、编译和测试不能证明所有真实窗口或玩家场景已覆盖。

## 仍待完成和验收

- 开发 / 配置：确定发布者公开身份和签名方式后，接正式安装器、签名后最终散列回执和更新信任；
  旧未签名预览到正式频道的过渡需独立处理，不能放宽正式发布门禁。
- 用户安排：干净 Windows 的运行库缺失 / 过旧 / 仅 x86 / 已满足、UAC 取消、安装失败、需重启后重入；
  最终同版本旧更新器下载、安装、失败回滚、再次启动和数据保留。
- 玩家验收：真实选人头像和装备方案商店展示；首轮关闭到 7 级、死亡与商店海克斯科技核心、
  刷新 / 短暂遮挡、跨局重置；IME、混合 DPI 和真实窗口行为。
- 产品边界：默认只识别主显示器游戏；UI 跨屏恢复不代表副屏采集支持。阶段数据可参考，
  未有可靠实际领取信号前保持未知 / 整体胜率。没有新增网站对局上传或自动游戏操作。
