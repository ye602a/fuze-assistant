# M2a：Rust 会话与检测调度核心

基于 PR #21 的纯 Rust 决策模块 fuze-runtime。本阶段迁移可确定的逻辑，不启动 LCU、网络、捕获、游戏进程或后台定时器；尚未把它接入生产宿主，不能声称正式软件已受益。

## 状态与边界

- 接收经上游验证的阶段、等级和选择界面类型事件。未知阶段不能启动截图；字符串解析不代表 LCU HTTP 认证成功。
- 数据身份强制带语言，例如 zh-CN@16.20.1。同版本跨语言也使上下文失效，旧结果不能写入新语言页面。
- 阶段、暂停、数据身份、捕获源切换递增 generation，清理等级窗口与帧去重；返回清理浮窗/停止捕获指令。实际执行清理由未来宿主负责。
- 一个在途 OCR 任务。超时只请求一次取消，必须等宿主确认 worker 已结束或任务实际返回，才能再次开始；超时不等于允许第二个任务并发。
- 迟到完成即使先于超时定时器回调也被拒绝。旧任务不能清除新任务状态；暂停/断线后的结果不显示。
- 单槽最新帧邮箱替换并释放旧值；拒绝重复序号、乱序帧和旧 generation。无需逐帧哈希或图像持久化。
- 每上下文最多容许三次失败，重试退避；达到上限停止，不无限重建。显式恢复或新上下文可重新尝试。

## 等级门禁

3/7/11/15 只指导检测节奏。即将到达等级可准备推理；选择界面短暂消失按刷新过渡处理，持续至少 6 秒、至少三次缺失后才结束高频窗口。碎片/未知界面不会标记正式领取。

正常高频间隔 250 ms，等级不可用时 1500 ms，节能阶段保留 8000 ms 兜底。等级超过 10 秒未更新自动失效，必要时提前唤醒；预览调度不会消耗实际截图机会。只有宿主开始处理时记录探测时间，避免被忙碌/重复帧吞掉兜底。

这延续现有等级门禁的启发式意图，不构成真实领取证明。Snapshot.actual_stage 始终 Unknown，selection_confirmed 始终 false，不开启分阶段自动排序。

wake_at 为宿主给出下一次唤醒时间。大厅、暂停、故障停止状态没有周期定时器；等待 worker 取消确认时等待事件，不轮询。所有时间戳要求来自同一单调时钟，不用墙上时间或日志时间推断。

## 验证

9 项定向 Rust 测试：碎片/刷新/延迟消失、等级失效与兜底、最新帧替换、暂停/断线/切换数据、超时取消与晚到结果、连续故障停止、语言隔离与未知阶段。依赖仅已有 contract/serde，不新增网络或异步运行时。

Windows CI 继续执行隔离 workspace 检查；不跑无关 Electron 大测试。本 PR 同时为前置 WGC CI 探针补充固定操作名/HRESULT，使用普通自有测试窗口代替工具浮窗，以便区分 API 失败阶段；正式原生浮窗样式未变，本机不运行可见探针。

## 尚未连接

LCU 发现/认证/WebSocket、真实等级输入、捕获 worker 进程管理、实际设备丢失后重建、数据下载缓存、设置界面均未接入。现有稳定版运行链路未变。这些宿主实现必须消费取消/清理指令，不能只调用 begin/finish 而忽略 worker 生命周期。
