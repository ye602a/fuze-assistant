# M2b：持久 OCR 工作进程与标题像素协议

新增 fuze-ocr-worker 和 fuze-worker-host。前者加载、预热一次模型后等待私有 stdin/stdout 管道；后者拥有子进程及一个阻塞管道线程，单次写入和读取共同受截止时间约束。等待期间无忙轮询。调用者应在后台控制线程运行阻塞 API，不能占用 UI 事件线程。

标题按左/中/右横向排列，只传原始 BGRA 和 generation/sequence/宽高；不传整帧、路径、账号或认证信息，不落盘、不做 base64、PNG、逐帧哈希。图集最多 1365×256×12 字节；结果最大 8192 字节；读取前验证长度，截断、旧序号和身份不一致被拒绝。

超时或协议故障只终止自己创建的子进程，并 wait 确认退出后才报告停止。启动也有独立截止时间；退出时回收管道线程。遵循 [Rust Child 文档](https://doc.rust-lang.org/std/process/struct.Child.html) 的显式退出/回收要求。当前没有跨进程自动重启循环；worker 内仍保留已有单次 DirectML → CPU 回退。原生崩溃后的 CPU 重启策略、父进程异常死亡保护仍待补齐。

离线验证连接了 GPU 标题回读 → 二进制管道 → 持久 OCR → Rust Session 验证及赛后空闲状态。18 个 workspace 测试通过。CPU/auto 各 3 个已提交样例×3 次、所有卡位一致，各仅启动一次 worker，最后确认回收。一次本机观察中 DirectML 整段约 19.6–21.8 ms，其中 OCR 约 15.8–18.1 ms；CPU 整段约 40.7–76.8 ms。包含缺卡/空卡样例，不能拿全部样例平均值比较三张完整卡性能。启动含模型预热约 CPU 0.39 秒、DirectML 2.32 秒，未计入逐帧延迟。

同一测试工具的显式探针覆盖正常返回、子进程异常退出、推理无响应、错误 generation、启动无响应；确认截止时间后已回收。测试不访问游戏、不创建窗口、不读取真实数据。

尚未做：真实 WGC 流和这个宿主在同一长期事件循环中的接线、暂停事件打断阻塞宿主的 UI 桥接、最终浮窗消息循环、游戏识别及压力验收。该工具不是正式应用，不替换 Electron。
