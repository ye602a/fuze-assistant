# M6b：原生更新、凭据和回滚

基于 PR #31；最终 Windows CI 38690492048 已通过并核验归档。独立 Rust 开发频道，不改变 Electron 稳定版的安装、配置或 Releases latest 指针。

## 玩家流程

- Start-preview.cmd 经原生 fuze-update.exe 启动当前托管版本，默认暂停。直接双击 fuze-rust-host.exe 只启动该文件所在版本，不经过托管指针。
- 暂停后“退出并检查更新”退出本 Rust 宿主并打开独立更新窗口。也可用 Update.cmd。检查、下载、安装均手动确认，后台无定时更新任务。
- 默认公开频道，完全不读取凭据库。私有频道通过 Private-channel.cmd 打开系统凭据输入框，以当前用户、仅本机的 Windows Generic Credential 保存；Forget-private-token.cmd 删除。无令牌参数、环境变量或明文配置。用户需仅此仓库 Contents 读取权限。
- 下载期间显示阶段并可取消。网络请求有界超时，取消在块/读取边界生效；系统阻塞调用不能立即硬取消。解包或自检期间取消会在切换指针前再次检查。
- 固定 GitHub 仓库 `ye602a/fuze-assistant` 的 `rust-preview` 预发布。清单、资产名、版本序列、大小与摘要一致才接受；不使用 Electron latest.yml，不让远端清单指定主机或安装路径。
- 允许 GitHub API 200 或有界 CDN 跳转；重定向只能进入内置 CDN 白名单，不能回到 API，CDN 永不携带 Authorization。公开频道无需密码，私有令牌不会发送给数据站。

## 下载与安装事务

每个文件独立 deflate 的 FUZEUP01 容器，索引有大小、数量、路径与展开体积上限；不使用 shell 解压，不接受链接、绝对路径、ADS 或跨目录条目。新包 SHA-512 验证一次，blockmap v2 仅用于优化；损坏基线或范围响应最多触发一次全量重试，取消不触发重试。完整下载是流式写入，不把整个包放进内存。连续块合并，复制 64 KiB、远端块最高 1 MiB；不影响游戏截图路径。

安装到 `%LOCALAPPDATA%/FuzeRustPreview/releases/versions/<revision>`，只有显式安装后才原子切换 current.json。首次安装复制本开发包到独立基线，后续保留上一版。包内 OCR 自检在隔离配置下运行，不连接游戏；新版本下一次启动前再次自检，桌面需要在 15 秒内发回固定就绪标记，否则回退并启动上一版。更新进程不自动重启正在运行的 Rust 或 Electron，不按进程名终止任何程序。主动 rollback 命令也只切换 Rust 指针。

这是 **用户确认的开发包安装**，信任固定 GitHub 仓库和 HTTPS 下载清单，尚无独立发布者签名；SHA-512 不是签名。自动下载安装仍关闭。要发布无需人工确认的生产更新，仍必须先完成发布者证书/签名信任配置，不能把此流程宣传为签名生产安装器。

## 发布契约与验证

`package-rust-preview.mjs` 先产生经过自检与内容扫描的 ZIP；`package-rust-update.mjs` 只从该 ZIP 生成 `.fuz`、`.fuz.blockmap`、`rust-update.json`。三件资产必须在同一个 `rust-preview` 预发布中完整更新后才开放；revision 取 Git 提交，sequence 取提交时间。禁止用历史 sequence 覆盖新包。当前代码不会自行创建或发布 Release。

本地针对性测试覆盖：坏块表全量回退一次、取消不重试、全量损坏拒绝、凭据输入约束、路径限制、自检失败不切换、指针占用不丢旧版、回滚后拒绝重复失败版本。开发包集成检查实际解包并运行原生 OCR 自检。CI 验证桌面和更新包，不访问真实账号或凭据库；系统凭据保存/删除 UI 和真实私有 Release 下载尚需发布测试资产后验收。

遗留边界：强制结束可能留下自己的 pending 目录，历史版本目前保留，容量上限清理另行推进；新进程已就绪后的后续业务故障不自动回滚。真实网络 Range/重定向链和已安装客户端的长期升级仍需实机验收，不能以合成测试代替。
