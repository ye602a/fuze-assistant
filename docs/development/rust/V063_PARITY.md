# 0.6.3 功能一致性审查

基准固定为 `v0.6.3` / `58aea5ee649c531220bed20db6307ff12dfad90c`。当前结论：**尚未通过完整一致性验收**。稳定版不替换，仓库保持私有；编译、契约测试、隐藏窗口和 CI 不能替代真实国服对局验收。

## 本轮验证边界

- 后续交互补查：四条出装路线均由同一隐藏窗口的真实处理函数切换并核对内容；标题/页脚点击隔离、说明层点击隔离与滚动、页面最后一行可达性已通过本地离线检查。固定说明层现在避开装备方案按钮，显示与点击共用几何范围；切换页签清除旧悬停说明；局内侧栏不响应不可见的选人槽位。临时隐藏后的恢复按可见性状态转换处理，仍需实战覆盖。
- 这些检查直接调用自有窗口处理函数，不模拟鼠标/键盘、不访问游戏。CI 报告为 `popup-review/interaction-checks.json`；不替代物理 DPI、全屏或玩家交互验收。
- CI #76 暴露过期计时缺陷：保留期剩余毫秒曾向下截断，提前到达的计时消息没有重新设置剩余时间，可能再次等待整个周期。改为向上取整、每次按原绝对截止时间重新设置一次计时；不延长 2.5 秒保留期，不增加持续轮询。该轮还遭遇 GitHub 产物存储额度不足，上传失败与功能测试失败分别记录，后续报告保留期缩为 7 天，未删除历史产物。

- 对照脚本从固定标签提取 renderer/shared/public，不把后续 Vue 改动当成 0.6.3。美术只使用仓库品牌与公开数据图标。
- 原生审查只渲染自己创建的隐藏窗口；直接调用这些窗口的导航、滚动与页签处理，不操作鼠标、不截图桌面、不启动/操作游戏、不读取真实账号或玩家日志。
- 通过库测试覆盖账号/区服隔离、SGP 解析/路由、装备方案保留、观察再出现与去重、数据更新事务、存储保留/清理、匿名图片和领取诊断的脱敏/过期规则。具体最终 CI 状态以本分支提交为准。
- 图片、网络、文件、解码不在绘制回调中运行。列表优先处理可见图标，单批与内存都有上限；资源监测每 2 秒只采样宿主和其 OCR 子进程。
- 账号摘要只在核实对局归属时计算，不逐截图哈希。存储预览仅检查元数据和清单，不重复哈希整份缓存；下载完整性验证保留。
- 个人观察使用隔离 Rust 数据路径，旧文件格式可读，未知/损坏文件不覆盖。匿名分享不带账号、区服、时间、gameId 或认证信息；没有上传日志和账号数据的代码路径。

## 完整放行条件

1. 完成上表逐项交互验收，尤其选人路线、键盘、设置与原版对照；明确候选网格的有意差异，不能将“已接入”当作“已一致”。
2. 对最终提交完成 Windows 构建、隐藏窗口、WGC 自有窗口、更新回滚及隐私检查。
3. 用户在真实国服完成至少一局完整选人→加载→三卡→刷新/遮挡→碎片/锻造器→赛后的验收；补充断线重连、多屏与 GPU 后端测试。
4. 实际领取轮次没有证明前，两版都保持整体胜率。这不应以推测补齐。
5. 全部迁移与发布审查通过后，才考虑替代安装包和仓库公开。
