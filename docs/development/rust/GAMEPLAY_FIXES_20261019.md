# Rust 头像、装备商店与等级门禁修复

本批基于 master `3d2f697`，只修改 Rust / Slint。源码和隔离测试完成不代表已发布或玩家实测通过。

## 核对到的缺口

- 头像：原内置映射仅覆盖 23 位英雄，公开目录有 173 位。一次远端失败会触发全局冷却，
  同一请求不自动重试，分批返回图片还会替换此前成功的映射。用户截图中可见的崔斯特、安妮
  恰好属于内置资源；没有读取玩家日志，因此不能判定当次远端失败的网络原因。
- 装备：Rust 已有手动 LCU Item Sets 写入，但原先导入多套方案、不跟随选中路线，
  后续装备组合只取首个物品，PUT 成功也没有回读确认。生产路径是选人期间写入客户端装备方案，
  游戏内商店再选择方案；不等于替换游戏默认“推荐”算法，也不自动购买装备。
- 等级：旧调度会在 6 / 10 / 14 级预热，首轮界面关闭后仍允许低频探测；死亡 / 复活也可唤醒。
  因此旧实现不符合“首轮识别结束到 7 级前停止识别”的约定。
- 误识别：旧标题匹配允许在更长文字里找名称子串，新的推荐也允许只凭一个匹配标题出现。
  这两处会放大商店或提示文字误入候选的风险。缺少当次商店截图，不能认定已复现全部像素条件。

## 本批行为

1. 补入另外 150 个公开英雄头像，附来源和 SHA-256 清单；173 个头像均可离线解码。
   下载失败按单图片退避、每次请求最多三次尝试，取消可唤醒等待；分批成功结果保留，
   缺失头像提供重试按钮。新增英雄仍走受限公开下载路径。
2. 手动导入当前路线，保留完整后续装备组合及核心 / 步数；方案标题包含路线、模式来源、补丁。
   在写入前重新校验选人、本人英雄与账号，保留非助手方案；PUT 后 GET 回读核对，
   缺失或不一致只显示“已提交但未核实”，不显示成功。
3. 新增默认关闭的“自动导入装备方案（本次运行）”。开启即授权导入本人当前查看路线，稳定一秒后执行，
   同一上下文不循环重试失败写入，失败可手动重试。离线预览、候选英雄和局内资料不能导入。
   授权只保存在内存，重启后关闭；不往旧设置文件添加字段，避免旧版回滚时拒绝配置。
   后台写入前检查当前授权，退出或撤销后不执行尚未开始的自动写入。
4. 首轮已识别候选且像素门禁确认界面消失后，本等级区间停止采集 / OCR；7 / 11 / 15 级才
   开启下一窗口。6 / 10 / 14 级不再提前唤醒；死亡、等级信号暂缺、暂停、数据切换和采集重建
   不解锁已关闭窗口。遮挡超时只清显示，不锁住窗口；仅属性碎片也不会关闭候选窗口。
   尚未看到候选、局中才启动或明确关闭等级门禁时仍允许有限探测，避免漏掉延迟选择。
5. 标题改为完整标准化匹配，保留有界同长度错字容忍和既有别名。
   新推荐至少需要两个不同的候选 ID；随后单卡残缺只能保留已确认的同槽位候选。
   OCR 仍可读出单个标题，但孤立的新标题不再独立开启推荐。

关闭识别窗口只是调度状态，不代表领取成功，不推算实际轮次；自动推荐仍使用整体胜率。
默认生产采集仍为主显示器 DXGI + GDI 回退。

- worker-host：105 项通过，含同局同英雄暂停 / 配置重建后的门禁恢复、跨局 / 换英雄清除、
  合成全卡 / 部分遮挡、多分辨率像素门禁与既有导出 / 更新回归。
- Slint：9 项通过，含 173 个头像离线解码、逐图片退避、自动导入去抖与去重。
- 真实 ONNX CPU 推理：仓库三组已有截图（完整三卡、残缺单卡、无匹配）全部符合预期。
  这是 OCR 层证据；单卡结果能读出不代表允许开启推荐。
- 生产 Controller 的截图回放新增暂停后 4–6 级零采集和孤立新标题不弹出的断言；
  此回放涉及隔离窗口，交给 Windows CI 执行，本机没有启动 FUZE 来替代实机验收。
- 两个 Rust 工作区格式检查、Git 差异空白检查及仓库敏感内容检查。

## 仍需玩家同版本实测

- 选人窗口五人、候选网格、英雄详情头像；断网和切英雄后显示是否持续完整。
- 在本人选人时手动 / 显式开启自动导入，再进入游戏商店选择 FUZE 路线，核对分组、完整装备和个人方案保留。
  GET 回读只证明客户端保存，不证明该游戏版本的商店展示或默认推荐页行为。
- 开场真实候选 → 关闭 → 4–6 级（含死亡、打开装备商店、查看海克斯科技核心）不再弹出推荐；
  7 / 11 / 15 级恢复，刷新和短暂遮挡不提前关闭；跨局状态正确重置。
- 首次画面只露一张卡时现在等待更多候选证据，需要核对真实遮挡场景中的可用性。
- 当前公开出装统计的 `queueId=450` 是普通大乱斗参考；海克斯专属适配、未有截图的商店误识别、
  真实窗口 / DPI / IME、安装签名 / 依赖引导与同版本更新回滚仍不因此通过。

本批未接入对局上传，不扩大网站数据贡献或游戏写入范围。
