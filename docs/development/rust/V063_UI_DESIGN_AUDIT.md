## 总体判断

已保留的是深蓝/金色方向、品牌图像、左侧导航与主要区域的大致顺序；尚未保留的是原设计的大部分细节、内容密度、响应式规则和完整页面。当前属于渲染技术样例，不能说“仅差输入法与跨屏”。此前性能结论仍有效，但不能扩大为产品视觉或功能一致性结论。

原版通过克制的边框、少量金色强调、语义状态色、线性符文图标、紧凑中文排版形成英雄联盟风格。当前原型把多类组件简化成同一金框矩形，层级和产品辨识度下降。无需新做一套设计，应按旧版恢复。

## 可量化的视觉差距

同为 1120×860 的参考：旧版状态区 x=214、y=179、宽866、高163.5；四模块 y=375、高137.19；最近识别外层面板 y=536.19、高272.55。当前原型固定状态区145高、模块114高、三卡124高，且没有识别外层面板。全页面垂直节奏发生变化，不是细微字形差异。

旧版 CSS：背景 `#07131e`、面板 `#101e2a`、金 `#c8aa6e`、正文 `#f0e6d2`。原型：`#07121b` / `#10232e` / `#d2b878` / `#e3e8e6`。需要恢复权威 token，再决定局部必要调整，不能仅以“都是深蓝金色”算通过。

920px 宽时，旧版侧栏158px、内容边距20px、模块2×2；原型侧栏180px、内容边距28px、模块始终四列。原型最小宽920，也没有旧版670px以下图标侧栏策略。是否保留更小尺寸支持可单独决定，但920px这档应先恢复。

局内三卡参考760×170，原型1032×300；在相同逻辑单位下矩形面积约为2.40倍。该数字比较设计尺寸，不比较不同DPI截图的物理像素，也不代表实际游戏遮挡已经测量。原型的品牌占位图有标注，但不能作为真实符文图验收。旧版参考图部分图标本身也回退为占位，因此本次不声称旧版参考图验证了图标下载成功。

## 允许保留的改动

1. 我方五人置顶，候选英雄使用按胜率排列的网格一览，和已选择区视觉区分。用户已明确确认，**不恢复旧版竖向候选滚动列表**。
2. 推荐数据卡保留实际数据版本；标签中的四模块没有直显版本号不是恢复时应该照抄的缺陷。
3. 缺失卡位保留槽位并提示“暂不可读，可能遮挡/刷新”，不认定一定是遮挡；刷新保留结果与碎片/锻造器分类沿用后续已接受行为。
4. 无可靠领取信号时继续整体胜率；手动阶段参考入口保留，不能用推测阶段替代实际领取。
5. Rust 后端、Skia 渲染、性能优化与隐私修复无需退回旧技术；界面外观与交互约束应保留。实验输入框、状态切换、关于页放独立验证入口，不能占据产品首页。
