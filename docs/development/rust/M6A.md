# M6a：原生桌面控制与更新边界

叠加 PR #30，独立开发包；稳定版的入口、配置和私有频道均不改变。本轮不合并、不发布正式安装器，不启动本机游戏发现或捕获。

## 玩家入口

- 双击 Rust EXE 或 Start-preview.cmd 打开原生 Win32/GDI 主界面。默认暂停；明确点击开始才允许 LCU 发现。沿用符择 ICO 和深色金色界面；DPI 变化重新布局，状态无变化不重绘。
- 顶部区分等待、识别运行、切出暂停、清理中、更新中和错误。四块显示客户端阶段、实际截图状态、worker 回报的 CPU/DirectML 后端、可用/实际启用的数据版本。不把配置为 auto 写成“GPU 已运行”。仅显示固定错误分类，不显示路径、端口、账号和凭据。
- 主窗口关闭时收起到托盘；托盘打开、暂停/开始、退出与主界面共用控制命令。Explorer 重建托盘时重新注册图标；注册失败不允许隐藏，关闭则退出。独立 mutex 防止多个原生桌面实例；不与 Electron 稳定版共享 mutex。
- 暂停立即取消旧推荐并使会话失效；后台清理捕获和 OCR，完成后才显示已暂停。暂停中的 LCU 不再请求，恢复通过线程唤醒。暂停的宿主使用条件变量等待；界面 250 ms 只比较一个最新状态，不进行截图、网络或文件 IO。
- 退出先停止识别与 LCU，清理 tray 和子进程。若 WMI/系统 IO 挂起超过 5 秒，则退出本宿主进程，由已有 Job Object 关闭所属 worker；不操作游戏或稳定版。此兜底不等同于系统 IO 已实现硬取消。

## 数据更新

暂停时可以手动“更新推荐数据”；下载期间开始识别或退出会请求取消。公网 TLS 严格校验，只访问固定数据站，不携带账号、LCU 凭据或 cookies，不接受重定向。

写入独立 `%LOCALAPPDATA%/FuzeRustPreview/client-data`；旧稳定版数据目录不变。每语言下载到临时目录，约束路径/语言/版本/体积，校验新下载文件 SHA-256，并通过现有完整数据解析后原子切换指针。只有更新时校验，不对截图帧重复哈希。并发更新使用独占文件锁；失败保留旧指针，激活失败恢复旧目录，无法回滚时保留恢复材料。三种语言分别提交，后续语言失败不撤销已完整更新的语言。

版本目录允许恢复“目录已落盘、指针未切换”的中断状态。保留历史完整版本；异常进程退出留下的临时目录及历史版本的容量治理尚需后续补齐，当前不全盘删除缓存。

构建流程改为 Rust 下载器准备公开数据资源，不重复跑 Node 下载器。`--prepare-data DIR` 是显式构建入口，与桌面自动发现无关。宿主下一次启动识别时才采用新数据，不在当前三卡显示中替换数据版本。

## 私有频道差分：已完成核心，尚未开放升级按钮

- 原生解析现有 gzip blockmap v2：有解压上限、单文件格式、块数量/尺寸/总大小限制；按校验标识与尺寸复用旧块。
- 复制和下载按 64 KiB 执行，可取消；范围响应必须是 206 且 Content-Range/长度完全一致。最终仅做一次流式 SHA-512，损坏基线不能产出可接受更新。
- GitHub API 固定到本仓库；CDN 白名单不传 Authorization。没有令牌落盘或来源日志。当前拒绝重定向，没有读取用户 GitHub 凭据。
- **未完成**：Rust 专属 release manifest/资产通道、重定向中凭据剥离的完整会话、令牌安全输入/保管、差分失败的一次全量回退编排、发布者签名验证和安装/回滚入口。当前只有核心 API 与测试，不能宣称已经支持玩家端私有频道升级，更不会拿 Electron 安装包覆盖 Rust。

## 验证与剩余边界

局部测试覆盖差分重建、基线损坏、取消、私有 URL 边界、三语言数据提交、损坏下载、指针被占用时回滚、暂停取消旧窗口。桌面 smoke 使用自有隐藏窗口和合成状态，不调用 LCU；生成的 PNG 仅是自有窗口渲染。Windows CI 可注册本测试的临时 tray 图标并验证恢复通知/删除，不移动鼠标或输入游戏。

真实客户端、实际游戏内暂停/恢复、不同 DPI/显示器、长期驻留、真实 Explorer 重启仍需玩家验收。当前桌面文案为中文；完整设置/界面国际化、战绩与选人界面、签名安装包仍未迁移完成。程序依赖 x64 VC++ 运行库，不自动安装。实际领取轮次保持未知，继续整体胜率。
