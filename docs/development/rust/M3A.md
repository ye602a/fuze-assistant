# M3a：本地数据读取与准备/激活分离

fuze-data 是只读数据模块，接受宿主明确提供的缓存/随包数据根目录，不扫描用户目录、不联网、不创建目录、不改旧配置或指针。支持 schemaVersion=3 的 current.json/current.<locale>.json，以及默认中文旧版本目录和按语言隔离的版本目录。

候选按数值数据版本排序，完整的新随包数据可以优先于旧缓存。不拼接不同根目录或不同版本的文件来凑“完整”。OCR 范围只需要 manifest 与 augments；Full 范围还验证 champions/items/champion-shards/index 和清单列出的分片。非默认语言要求指针和 manifest 明确声明该语言，载荷若声明语言/版本也必须一致。

全部文件在 prepare 阶段有限读取/解析，核对清单声明的字节数、路径边界和数据结构。拒绝 Windows 设备名、路径穿越、符号链接/reparse point、超大输入、同名不同 ID。不计算或反复计算哈希；没有联网完整性认证的含义。整个版本来自一个明确根目录，数据准备成功之后才能 activate；失败保留旧快照。正在识别的任务用 Arc 保留自己的旧快照，上层同时用 Session generation 拒绝旧结果。每帧无需磁盘 IO。

本阶段只有内存激活，没有持久化指针写入。只接受数值点分版本（最多六段）；仅含 URL 而无逻辑路径的 manifest、其它 schema、任意新版本格式不猜测兼容。不默认把中文数据改标成英文。

三个定向测试覆盖新随包/旧缓存选择、不完整新版本回退、OCR 最小范围、跨语言拒绝、失败不切换、旧 Arc 保留、路径别名、声明大小不匹配和歧义识别字典。所有文件均在测试创建的临时目录；没有读取实际安装数据。

尚未完成：远程增量数据准备、落盘事务/回滚、多渠道字典合并、统计排名、旧 schema 迁移，以及宿主/界面接线。当前不是完整 data-loader.ts 的替代品。
