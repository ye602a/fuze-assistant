# M5d：事件连接、凭据回退与便携开发预览

叠加 PR #29；稳定版的入口、安装目录和用户配置不变。验证只使用固定样本、自有测试窗口或临时 localhost 服务，未访问玩家游戏、账号接口或运行日志。

## 本阶段完成

- LCU WebSocket 使用原生异步 WinHTTP，固定 loopback TLS，无代理/重定向。101 升级后发送 WAMP 订阅；阶段、英雄、对局和语言事件只触发认证 HTTP 复核，不直接作为可靠状态，更不推断领取轮次。
- 接收缓冲 4 KiB、重组上限 256 KiB、完成队列 8 项；相关事件合并，HTTP 最快间隔 100 ms。收到相关事件后健康轮询改为 5 秒，否则保持 2 秒；WebSocket 失败继续 HTTP，30 秒后重试。回调只投递完成消息，不做 JSON/OCR/界面工作。挂起接收取消后，回调上下文保留到最终关闭通知。
- 自动发现优先已核实 LeagueClient.exe 的同目录 lockfile；不可读时从已核实路径、保留存活句柄的 LeagueClientUx.exe 获取 PID 限定 WMI CommandLine。Windows 原生命令行分词；临时凭据文本擦除，歧义和权限失败不猜测。不使用 shell、全量命令行输出或进程内存读取。
- 自动语言读取 /riotclient/region-locale，支持 zh-CN、zh-TW、en-US。错误/未知语言阻止自动会话，不默认为中文。语言变化取消旧结果并重建匹配语言的数据；最近验证时间来自真实 HTTP 完成，缓存轮询不会刷新验证时间。
- 相对配置路径按配置文件目录解析。新增 --check-bundle 只检查随包三种语言数据并启动/回收 CPU OCR worker，不发现客户端、不访问游戏、不创建窗口或读取用户缓存。
- 开发 ZIP 仅包括两份 Rust EXE、四份运行时 DLL、模型/字典、构建资源目录中公开数据 manifest 指定的必要 JSON（不扫描用户目录）与固定说明/配置。只在打包时计算一次压缩包 SHA256；无逐帧哈希、截图文件、账号配置或稳定版缓存。打包前扫描内容。自检在另一个工作目录运行，不添加源码运行时目录到 PATH。

## 验收边界与剩余差距

| 模块 | 当前证据/下一步 |
| --- | --- |
| WebSocket | 隔离 localhost 服务验证实际升级、分片、401 拒绝和挂起接收取消；生产只走 TLS，但真实国服 WSS 尚未实测 |
| 命令行回退 | Windows 编译与参数/歧义拒绝测试；真实 WMI 权限和腾讯布局仍待实战验证 |
| 自动语言 | 严格解析与宿主取消接线；实际客户端切换语言仍待验证 |
| 截图→OCR→数据→浮窗 | 延续已有原生整链路，CI 使用自己的窗口和固定样本；未自动捕获玩家游戏 |
| 便携开发预览 | 离线数据、模型、DLL 布局和 worker 回收自检；不是正式安装包 |
| 正式主界面/托盘/设置/暂停 | 尚未完整迁移，命令行不能作为最终玩家界面 |
| 数据和程序更新 | Electron 的私有频道/差分更新没有迁移；Rust 当前只读本地数据，随包补丁不保证最新 |
| 等级和实际领取轮次 | 未完整接入可靠实际领取信号；保守调度、整体胜率保留，不能靠等级或属性碎片猜轮次 |

| 玩家功能和发行 | 选人推荐完整 UI、战绩、可见诊断、安装器、签名和第三方许可清单仍需收尾；独占全屏、多屏/DPI、断网/重连、长时实战仍待验证 |
