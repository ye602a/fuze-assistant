# 腾讯 101 海斗推荐接入

## 运行路径

只读取 `https://mlol.qt.qq.com/go/battle_info/odp_proxy/fuwen_hero_rank?championid=<ID>`。
它是 101 海克斯大乱斗详情接口，不使用普通大乱斗榜单；没有凭据、个人 Key 或上传请求。
Slint 详情先显示本地数据，再异步取得补充；切换英雄取消旧请求，网络等待不占用详情线程。
进入对局后由独立后台任务补充当前英雄排名，返回结果不触发截图或改变识别门禁。
离线检查不创建网络任务。

公开响应按英雄缓存，6 小时内复用；失败时只使用仍有效的同英雄快照，否则保留原来源。
统计日期超过当前日 3 天、请求英雄不符或字段格式错误时不启用。此适配器的装备目录固定
16.21，仅匹配该补丁的简中数据身份；以后升级目录须重新核对购买条件，不把统计日期当补丁。

## 排名、胜率和阶段

`augment_json_irank` 的六列为排名、英雄 ID、强化 ID、品质、选取率、评级。
只补排名、选取率和评级；保留当前资料里的品质，避免把“连锁反应”黄金/棱彩的源冲突带入识别。
原 `winRate/wins/games/winRateSource/winRateRegion/winRateGamePatch` 不被腾讯排名覆盖。
新出现的组合使用现有当前强化目录补资料，不复制全局胜率。无官方排名的条目不混入新排名分数。
分阶段仍由现有 ARAMKit 接线提供，未增加领取轮次推断。

## 装备展示和商店导入

出门、鞋子、核心、备选和六件组合均按选取率排序；部分字段为万分比，统一转为 0–1。
界面标记腾讯101、统计日，以及补丁和样本数未提供。组合用并列分隔，不伪装成购买顺序。

`resources/tencent-mayhem-items-16.21.json` 联结腾讯当前装备目录及已保存的 16.21 简中客户端目录。
`scripts/prepare-tencent-items.mjs` 从两份公开 JSON 重建，来源和输入 SHA-256 随资源保存。
客户端目录为 2026-10-22 研究保留的导出；2026-10-25 重取该公开 URL 返回 403，未绕过访问限制。

- 可购买标记、英雄/盟友/强化货币等条件共同约束；腾讯地图标为未知的变体，仍须有客户端
  可购买证据且实际出现在海斗接口中，不能靠删除 ID 前缀改成普通装备。
- 通过客户端 `specialRecipe` 映射成长装备，例如 3121→3119、3040→3003、3042→3004、2530→2526。
  显示原成装及其统计，导入可购买前置装备；界面明确这项转换。
- 条件或特殊装备不自动导入，界面列出原因；一个组合含未知/条件装备时整组跳过，不截断成残缺组合。
- 只生成 queueId=2400 的方案，关联地图12；沿用现有受管 UID，不覆盖玩家自建方案。
- 使用现有 LCU 选人/本人英雄/账号检查与 GET→PUT→GET 读回确认。HTTP 成功但读回不符仍报告失败。

## 必要验证与边界

仓库保留两个公开匿名英雄响应作为回归样本。数据测试覆盖比例单位、来源保留、模式隔离、
成长装备、特殊装备、未知组合、重复排行、错英雄和格式错误；宿主测试贯通解析、装备组、
玩家方案合并和失败读回，并测试缓存过期与取消。

2026-10-25 隔离目录的 173 个公开英雄响应均通过生产解析和装备组生成，得到 173 份海斗方案，
全部导入 ID 都在经过购买条件核对的目录中，并通过模拟 LCU 合并/读回。
这证明接口转换和商店装备组协议，不等于国服商店实机验收。尚需玩家在选人导入后，确认
游戏内推荐装备组可见、普通装备可买、成长装备显示前置项、条件装备没有进入购买列表。
