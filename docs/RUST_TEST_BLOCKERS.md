# Rust 测试包阻断回归：2026-10-16

> 历史问题记录，非当前待办。之后补齐了手动目录不依赖进程元数据、非 UTF-8 日志前缀解析等修复，用户确认连接恢复，修复已进入 56ca08c45a63。保留以下复现与证据用于防回归；不能据此断言最新版仍卡在发现阶段。当前剩余验收见 [交接文档](CODEX_HANDOFF.md)。

用户反馈来自一直用于 FUZE 测试的同一台电脑。旧版可用不代表 Rust 迁移版已覆盖旧版发现路径；不得归因为新环境。旧包 `84a0241cf772` 的实战放行撤回，稳定版保持原样。

## 已确认的问题

1. **导航点击被焦点层截断。** 使用自有隐藏 Slint 窗口的指针移动、按下、松开事件复现：点击战绩后 expected=1 / actual=0。此前直接设置 page 属性、调用回调的检查绕过了事件命中，不能证明用户点击有效。
2. **旧版 LCU 日志回退迁移遗漏。** Electron 的 `process-auth-discovery.ts` 和 `manual-directory-auth.ts` 支持 LeagueClientUx 日志；Rust 原来只有 lockfile 与 WMI 命令行。缺少 lockfile、命令行不可读时，旧版存在的恢复路径丢失。它是否是此次现场唯一原因尚未验证。
3. **错误原因被笼统标题掩盖。** “客户端连接异常”无法区分凭据发现、认证、HTTP、阶段或传输问题。

## 修复边界

- 自定义键盘 FocusScope 关闭自动点击夺焦；TouchArea 完成点击后显式设置焦点。保留键盘激活、确认框拦截和现有布局。
- 命令行失败才读取当前 UX 进程的启动日志，自动目录和手动回退均支持。保留进程句柄检查、PID 绑定与多客户端拒绝猜测；只查已知目录，单目录最多 4096 项，最多读取 3 个文件各 256 KiB，不递归扫盘。日志名须匹配 PID，文件创建时间不得早于当前进程启动；没有可确认来源时保持失败。
- 凭据仅短暂留在本机内存，临时读取缓冲在释放前清零；不记录或导出正文、认证 URL、端口、密码、账号。解析日志不代表连接成功，仍需现有 LCU 请求与阶段校验。
- 首页和连接模块直接显示具体原因及固定错误码；连接失败仍允许打开设置、查看已有本地记录。在线战绩仍依赖连接和明确区服。
- 观察不等于领取，推荐维持整体胜率。本批不修改游戏、不模拟系统输入、不安装或启动在线助手，不发布正式 Release。
