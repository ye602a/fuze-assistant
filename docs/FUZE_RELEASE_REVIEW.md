# Fuze 0.4.0 发布检查

检查日期：2026-10-10。范围：当前完整项目的构建与类型边界，以及本分支新增的连接状态、截图/OCR 生命周期、等级调度、缓存、弹窗、IPC、授权与发布链路。此记录不包含本机日志、账号资料或凭据。

## 修复与确认

- 移除原作者更新配置对本分支升级的控制，只允许 `ye602a/fuze-assistant` 私有 GitHub Releases。私有凭据经 Windows safeStorage 加密保存，IPC 不提供读取明文的接口，错误信息仅返回固定分类。
- 更新不自动下载、不随退出安装；进入选人/对局取消下载，安装前另行检查游戏进程，状态不明确时拒绝安装。未配置发布者签名，保留用户显式确认，不把哈希校验当成 Authenticode。
- 发布安装包统一使用不含空格的资产名称，使 `latest.yml` 与私有 GitHub provider 的文件匹配规则一致。发布脚本只推送当前版本的附注标签，避免把上游历史标签一并发布；CI 不覆盖已发布版本的资产。
- 修复等级读取的总超时、OCR 回退初始化取消与回退后超时清理；生产版识别字典仅从指定资源和数据目录读取，开发模式补齐源码字典路径。
- 改造三卡和详情窗为统一的 Fuze 配色与布局；保持游戏左右顺序，优先推荐与历史统计分开表示；补全等级设置翻译，图标网络失败时显示简洁占位。
- 继续保留 contextIsolation、sandbox、webSecurity 与可信 IPC 检查。源码扫描没有发现新增的 `v-html`、`eval` 或关闭上述安全边界的配置。
- 清除未使用的 Firebase 依赖；升级 Axios、Sharp 和相关解析库，并更新 Electron 42.11.12。没有运行跨主版本强制修复。

## 验证

- 65 个测试文件、290 项单元测试通过；包含私有更新的加密、错误脱敏、重复检查合并、对局限制、取消下载、哈希错误和便携包限制。
- 类型检查、代码规范与生产构建通过；npm 10 按锁文件重新安装通过。
- 三卡、单卡、无匹配画面及原始像素的 OCR 固定样本回归通过。
- 真实 Windows 打包应用的四个窗口完成 preload/renderer 就绪与 IPC 检查；隔离环境中运行 GPU OCR、CPU 模式、GPU 故障回退和截图链路检查。
- 另对设置页密码输入、授权不回显、布局溢出和高级目录默认折叠做打包检查。截图测试保持隐藏，仅通过测试应用自身 DOM 操作，不使用 OS 鼠标键盘。
- 发布树排除运行配置、个人日志、缓存、压缩备份和签名私钥；没有发现 GitHub token、私钥或本机用户绝对路径模式。

## 已知边界

`npm audit --omit=dev` 为 0 项，但这不等于程序已无漏洞：Electron 和浏览器依赖虽然列在 devDependencies，也会打入程序，已单独检查并更新。完整依赖审计仍有 11 项报告（8 moderate、3 high），涉及构建工具链和未使用的 Vue SSR 渲染器；客户端没有 SSR 入口，不对外提供开发服务器。保留这些条目用于后续维护，不用降级构建器的方式凑成 0。

窗口/OCR 检查采用隔离样本与本地桌面捕获，不能代替实际腾讯国服对局验收，也不能用这些结果推断实战 CPU 占用降幅。发布后需另验证私有仓库的真实检查和下载；本次不会自动执行安装或重启用户程序。
