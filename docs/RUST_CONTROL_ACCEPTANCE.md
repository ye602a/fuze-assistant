# Rust 当前功能与逐控件验收

2026-10-16。基线：`v0.6.3`（`58aea5ee649c531220bed20db6307ff12dfad90c`）、Rust 迁移清单 `development/rust/PLAN.md`、`V063_PARITY.md` 及当前 Slint 源码。本批基于 PR #69，不替换稳定版、不打包、不发布、不公开仓库。

**判定：已完成本批可安全执行的逐控件检查并修复发现的入口遗漏；不能判定完整迁移验收通过。** 560 是检查项数量，包含重复尺寸、键盘、禁用与状态断言，不是 560 个独立按钮。系统对话框、真实游戏和未实现功能列在下文，未被算成通过。

## 为什么之前的证据不够

之前主要从 Rust 直接调用回调，能够证明服务有实现，却不能证明玩家点击实际能到达它。PR #69 已修复外层 FocusScope 截获点击；本批改为逐一定位实际组件的可访问性标签，通过 Slint WindowEvent 分发位置点击、键盘和滚动，再核对回调及页面状态。测试不会移动系统鼠标、投递 Windows 输入消息或改变系统输入焦点。

另有独立的真实服务检查：同样从组件点击进入设置、战绩、分享、存储和导入服务；仅使用新建隔离目录和合成数据。真实网络、文件对话框、凭据存储、剪贴板和游戏写入不在这一路执行。没有用假回调的成功代替这些外部行为。

- `cargo test --workspace --lib --locked --offline -j 1`：117 项通过，0 失败。包括安装/回滚、隐私/缓存、LCU、识别/调度；不等于真实客户端验证。
- 本地构建是顶层低优化功能验收构建，**不可作为性能成绩或玩家包**。CI 使用正常 release；审查 feature 不进入正常打包命令。
- 本批没有系统输入、桌面截图、真实游戏访问、原始玩家日志/账号读取、令牌读取、稳定版安装/重启或 Release 上传。系统动作的 UI 路由使用记录器，不会执行其外部副作用。

CI 会执行上述逐控件与服务检查，避免以后只靠编译和直接回调放行。未完成项仍保留在清单，不能宣布“所有功能无遗漏且全部可用”。


## 2026-10-17：中文版预览候选的操作反馈收口

本轮只修复现有入口，不扩展迁移范围。用户已确认连接修复包正常，但仍报告部分按钮无反馈；因此不再用“回调已绑定”代替操作可用性。

- 主窗口的操作反馈固定在可视区域，设置、战绩、维护和窗口错误不再藏在页面上方。保留原中文导航、模块、颜色与布局。
- 偏好、目录、暂停/继续、战绩、数据更新在接受请求后立即进入处理中；结果由宿主完成状态回传，不能把排队当作保存成功。重复提交相同设置也能结束处理中状态。
- 战绩页新增暂停并管理入口，刷新/缓存/更多与服务的暂停条件一致。请求失败保留当前已显示记录，不用空列表替换。
- 旧设置/战绩/观察导入统一显示等待与完成状态；取消文件选择和确认有明确反馈。匿名分享的生成、保存、复制反馈保持区分。
- 更新检查区分授权不存在、取消、访问或频道不可用、超时和发布资源不完整；失败后不保留旧的“可安装”提示。扫描明确说明可清理数量为零，清理后重新扫描。
- 选人装备配置反馈固定可见；查看队友/候选英雄和局内只读资料时，按钮明确说明当前不可配置的原因。取消配置明确不写客户端。
- 未新增定时扫描、游戏接口请求、截图或网络自动操作；仍使用原有宿主事件与轮询。

验证记录：两种窗口尺寸下 574 项组件事件/状态检查通过（含重复尺寸与禁用检查，绝非 574 个独立按钮）；隔离服务验收通过，包含即时等待、滚动到底仍能看到目录错误、偏好应用、战绩详情/分页、匿名分享、扫描清理保留与确认取消。实际查看了原生渲染的设置错误和窄窗口分享反馈。所有输入仅分发到自有隐藏组件，不使用系统鼠标/键盘，不读取游戏或个人数据。

预览范围：可面向已有测试用户提供简体中文 Windows 预览候选，保留稳定版。发布前仍要求该提交 Windows CI 和正常优化构建通过；不把调试审查二进制打包。完整迁移尚未宣告完成：上表的其他界面语言、详细领取诊断导出、完整诊断日志、可选符文页写入和未实测 OS/实战场景仍保留，不算作被移除。实际领取未知，三卡自动推荐继续整体胜率。不得因此公开仓库或替换正式稳定版。
