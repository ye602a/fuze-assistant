# 符择玩家指南

[返回首页](../README.md) · [下载 Windows 版](https://github.com/ye602a/fuze-assistant/releases/latest) · [版本记录](https://github.com/ye602a/fuze-assistant/releases)

## 下载与启动

- **推荐使用安装包**：在正式发布页下载 Setup 安装包，选择目录安装，再通过 FUZE 快捷方式启动。安装包包含所需 VC++ DLL，不需要单独安装运行库；安装结束不会自动打开程序。
- **便携包**：下载程序 ZIP，完整解压后运行包内的 `FUZE.exe`。历史 ZIP 的依赖可能不同，以对应发布说明为准。
- 需要 Windows x64。当前安装包未签名；卸载可使用 Windows 的“已安装的应用”，设置和个人数据不随程序卸载删除。
- GitHub 的 Source code 压缩包是源码，不是运行包；`.fuz`、`.blockmap` 和 JSON 是更新器使用的文件，不要双击安装。
- 历史发行包继续保留，不要同时运行两套助手。具体功能以所下载版本的发行说明为准。

启动并登录英雄联盟，再打开符择。在大厅先确认首页“通信已验证”，并检查战绩与设置能打开，再进入对局。没有连接成功时不必为了测试进入游戏。

## 连接与窗口

自动发现优先，游戏目录只是高级回退项。“发现客户端进程”不等于认证或游戏阶段读取成功。失败时记录首页固定错误码、版本和发生时间，不发送账号、临时密码或原始日志。

选人窗口顶部展示我方五人，下方按胜率展示候选英雄网格。候选数据是参考，不会替你选择或交换英雄。置顶与浮窗相关行为可在偏好设置调整。

点击右上角 X 可选择退出、最小化或取消。最小化继续后台运行，退出才会停止助手。窗口预览仅用于检查显示，不代表本局识别成功。

大厅中截图与 OCR 待命是正常情况。对局出现三卡后仍无结果，或结果反复闪灭，请记录发生在首轮、刷新还是遮挡时；不要用“进游戏多久”代替“卡片出现后等待多久”。

## 推荐与数据

- 首页显示连接、画面、识别和数据模块的状态，同时保留数据版本。
- 三卡位置与游戏保持一致；未读到的卡位不由其他识别文字补齐。
- 自动推荐继续使用**整体胜率**。可查看四阶段胜率参考，缺失显示“—”，少样本会标注。
- 未可靠确认实际领取轮次前，不按等级、弹窗次数、刷新或属性碎片推断已领取。
- 完整缓存优先展示，远端检查在后台进行。不同来源、补丁或统计口径不能混成同一组胜率。
- 识别观察不等于实际领取记录；本地战绩也不等于完整账号历史。查询失败时保留已有缓存。

FUZE 使用 ARAMGG 上游的公开数据接口及部分图片资源，程序更新由 FUZE 自己的 GitHub 发布渠道提供。来源与第三方说明见[致谢](../THANKS.md)。

### 更新推荐数据

在“设置 → 数据与更新”点击“检查数据更新”。只更新简体中文资料，显示检查、文件下载与校验、启用数据的实际进度；结束后保留结果。同版本的完整数据不会重复下载。

资料与统计的版本不匹配时会明确显示。这里比较的是符文资料与统计数据，不代表已经检测过游戏客户端版本；“没有更新的推荐数据”也不代表数据站已跟上游戏补丁。缺失或版本不匹配的强化统计显示“暂无统计”。

存储管理和旧设置迁移默认收起，需要时再展开。

主程序入口为 `FUZE.exe`，`fuze-update.exe` 是独立更新器。安装目录中的 DLL、模型、数据、`preview.json` 运行配置及 Windows 卸载文件仍在使用，不要单独删除。

## 程序更新

在“设置 → 数据与更新”检查程序更新，发现新版后点击“更新并重启”。当前更新频道仍使用 `rust-preview` 地址，与正式版下载页可能不是同一构建；以程序检查结果和各发布页说明为准。

“当前没有可安装的新版本”可能表示已是频道最新版本，也可能是已知新版本尚未发布完整包；以页面具体状态和[更新频道发布页](https://github.com/ye602a/fuze-assistant/releases/tag/rust-preview)为准。使用历史版本时，先确认其发行说明中的更新入口；跨版本切换可从正式发布页完整下载。

新版更新器优先差分下载，条件不满足时下载完整包，校验后覆盖当前程序目录，完成后自动打开新版。下载期间可以继续使用；更新窗口准备好后自动停止识别、退出主程序并替换文件，随后打开新版。设置和个人记录保留。使用历史版本时以该版本实际提示为准。

从 0.7.1 起，设置页显示 `0.7.X` 版本号；构建编号继续保留在反馈报告中，便于区分同版本的不同构建。源码 PR 合并后仍需发布程序包，才会出现可安装的更新。

## 反馈问题

在程序中导出反馈报告：

1. 打开“设置 → 帮助与反馈”。
2. 导出脱敏反馈报告，保存生成的 JSON 文件。
3. 在 [Issues](https://github.com/ye602a/fuze-assistant/issues) 或当前排障对话中附上这个文件，并写明版本、现象、发生阶段和大概时间。

不要上传整个数据目录、原始日志、战绩缓存、配置或认证信息。截图请先裁掉账号、好友列表与聊天。

可选的“GitHub 公开诊断反馈”用于自动创建报告，**需要独立的 Issues 写入授权**。公开仓库并不允许匿名写入。令牌保存在本机 Windows 凭据管理器，不随程序分发；开启后每局赛后上传摘要，首次明确故障可能提前反馈，赛后更新同一份报告。

“待传 0 份”不代表报告已上传；“最近报告 #编号”才是成功回执。网络或授权失败会保留队列，也可改用手动导出。详情见[测试与反馈指南](RUST_PLAYER_TEST_GUIDE.txt)。

## 遇到问题时

请说明问题发生在选人、首次强化、刷新还是赛后，并附上程序版本。遇到持续掉帧或抢焦点时，可以先退出 FUZE，结束游戏后再导出反馈。

游戏在主显示器、无边框或窗口模式下使用。若涉及输入法、不同缩放比例的显示器、远程桌面或独占全屏，请一并说明环境，方便复现。
