# 符择玩家指南

[返回首页](../README.md) · [下载安装包](https://github.com/ye602a/fuze-assistant/releases/latest)

## 开始使用

1. 从 Releases 下载 `Fuze-Setup-版本号.exe` 并安装。源代码 ZIP 不是安装包。
2. 启动并登录英雄联盟，再打开符择。客户端优先自动发现，通常不用填写游戏目录。
3. 在首页查看连接验证和游戏阶段。进入海克斯大乱斗后，三卡出现时等待识别和推荐。

仓库目前为私有，需要仓库访问权限并登录 GitHub 才能下载。以安装包发行说明为准：主分支可能包含尚未正式发布的功能。

## 连接与窗口

“已发现客户端进程”不等于认证成功或读到游戏阶段。客户端已登录但仍等待时，在偏好设置中打开本地日志，记录软件版本、发生时间和错误类别。手动游戏目录是高级回退项，不是必填项。

英雄详情顶部提供备选英雄参考，不会替你选择或交换英雄。“选人时置顶英雄详情”默认开启，可在偏好设置中关闭；进入游戏后仍按隐藏设置处理。该选项需要包含修复的新安装包。

没有三卡弹窗时等待识别属于正常情况。画面采集失败时可尝试无边框或窗口显示模式。设置中的窗口预览有助于区分显示和识别问题；预览不是本局结果。

## 推荐与数据

三卡左右位置与游戏对应。统计仅供参考，不保证单局表现。分阶段统计目前用于手动参考；未可靠确认实际领取轮次前，不会仅凭等级、弹窗次数或属性碎片自动切换排序。

已有完整数据优先从本地读取，在线检查在后台完成。离线展示取决于缓存或安装包已有数据。不同来源或补丁的统计不能直接混作同一组胜率。

国服战绩查询受接口和区服识别影响，失败不代表 OCR 同时失效。本地记录只覆盖符择实际记录到的内容，不等同于完整账号历史。偏好设置提供存储查看和按类别清理。

## 私有频道更新

使用有权访问仓库的 GitHub 账号创建仅限本仓库、Contents 只读权限的细粒度访问令牌，在偏好设置中启用私有频道并填写。令牌通过系统加密保存在本机；无法安全保存时会拒绝保存。不要将令牌粘贴到聊天、Issue、截图或源码中。

检查、下载和重启安装由你主动发起。选人及对局期间阻止下载和安装，进入相关阶段取消更新下载。当前私有频道的增量下载尚未完成验证，仍可能下载完整安装包。
