# 符择玩家指南

[返回首页](../README.md) · [Rust 测试版](https://github.com/ye602a/fuze-assistant/releases/tag/rust-preview) · [v0.6.3 稳定版](https://github.com/ye602a/fuze-assistant/releases/tag/v0.6.3)

## 下载与启动

- **Rust 测试版**：下载 `fuze-rust-preview-*.zip`，完整解压后运行 `Start-this-build.cmd`。它会启动当前解压包，避免误开此前安装的旧版。需要本地安装时再使用包内 `Install-local.cmd`。
- **v0.6.3 稳定版**：下载 `Fuze-Setup-0.6.3.exe` 并安装。这是保留的 Electron 版本。
- GitHub 的 Source code 压缩包是源码，不是运行包；`.fuz`、`.blockmap` 和 JSON 是更新器使用的文件，不要双击安装。
- 仓库现已公开。Rust 测试版下载和更新无需令牌，旧版的私有频道授权说明不适用于它。
- 保留稳定版可供回退，但不要同时运行两套助手。具体功能以所下载版本的发行说明为准。

启动并登录英雄联盟，再打开符择。在大厅先确认首页“通信已验证”，并检查战绩与设置能打开，再进入对局。没有连接成功时不必为了测试进入游戏。

## 连接与窗口

自动发现优先，游戏目录只是高级回退项。“发现客户端进程”不等于认证或游戏阶段读取成功。失败时记录首页固定错误码、版本和发生时间，不发送账号、临时密码或原始日志。

选人窗口顶部展示我方五人，下方按胜率展示候选英雄网格。候选数据是参考，不会替你选择或交换英雄。置顶与浮窗相关行为可在偏好设置调整。

Rust 测试版点击右上角 X 可选择退出、最小化或取消。最小化继续后台运行，退出才会停止助手。窗口预览仅用于检查显示，不代表本局识别成功。

大厅中截图与 OCR 待命是正常情况。对局出现三卡后仍无结果，或结果反复闪灭，请记录发生在首轮、刷新还是遮挡时；不要用“进游戏多久”代替“卡片出现后等待多久”。

## 推荐与数据

- 首页显示连接、画面、识别和数据模块的状态，同时保留数据版本。
- 三卡位置与游戏保持一致；未读到的卡位不由其他识别文字补齐。
- 自动推荐继续使用**整体胜率**。Rust 测试版可查看四阶段胜率参考，缺失显示“—”，少样本会标注。
- 未可靠确认实际领取轮次前，不按等级、弹窗次数、刷新或属性碎片推断已领取。
- 完整缓存优先展示，远端检查在后台进行。不同来源、补丁或统计口径不能混成同一组胜率。
- 识别观察不等于实际领取记录；本地战绩也不等于完整账号历史。查询失败时保留已有缓存。

## 公开测试频道更新

Rust 测试版在设置中检查对应测试频道。只有维护者发布了新的更新清单和完整资产，才会出现可安装版本；GitHub 主分支领先或 PR 已合并，不代表已发布新包。

“当前没有可安装的新版本”可能表示已是频道最新版本，也可能是已知新版本尚未发布完整包；以页面具体状态和 [Rust 测试版发布页](https://github.com/ye602a/fuze-assistant/releases/tag/rust-preview)为准。v0.6.3 的更新入口与 Rust 测试频道不同，切换版本请从对应发布页下载。

检查、下载和安装由你主动发起。支持差分的版本会在基线与服务器条件满足时复用旧包；条件不满足时回退完整下载。查看页面实际显示的下载方式，不能仅凭包体大小判断差分是否生效。差分不会在对局中热替换程序，选人与对局期间不安装更新。

## 反馈问题

不需要上传令牌也能反馈：

1. Rust 测试结束后正常退出 FUZE，等待约 5 秒。
2. 在解压目录运行 `Export-feedback.cmd`，获得 `Fuze-feedback-xxxxxxxx.json`；也可在程序内导出脱敏反馈。
3. 在 [Issues](https://github.com/ye602a/fuze-assistant/issues) 或当前排障对话中附上这个文件，并写明版本、现象、发生阶段和大概时间。

不要上传整个数据目录、原始日志、战绩缓存、配置或认证信息。截图请先裁掉账号、好友列表与聊天。

可选的“GitHub 公开诊断反馈”用于自动创建报告，**需要独立的 Issues 写入授权**。公开仓库并不允许匿名写入。令牌保存在本机 Windows 凭据管理器，不随程序分发；开启后每局赛后上传摘要，首次明确故障可能提前反馈，赛后更新同一份报告。

“待传 0 份”不代表报告已上传；“最近报告 #编号”才是成功回执。网络或授权失败会保留队列，也可改用手动导出。详情见[测试与反馈指南](RUST_PLAYER_TEST_GUIDE.txt)。

## 测试建议

先正常玩 2 局，关注自动连接、选人更新、首轮三卡、自然发生的刷新/遮挡及赛后清理。遇到完全不识别、持续掉帧或抢焦点时直接退出并反馈，不必凑局数，也不必为了测试改变游戏操作。

当前以简体中文 Windows x64 为主要测试环境。中文输入法、跨屏 DPI、远程桌面和独占全屏应按实际测试情况判断；CI 或离线样本通过不代表这些环境全部验证。
