## 3. 当前架构与完整路径

应用业务为 Rust。主界面、设置、战绩、选人和次级面板使用 **Slint + Skia**；三卡使用 **Direct2D + DirectWrite**。不是 WinUI 3，也不是 Electron 套壳。ONNX Runtime、DirectML、Skia 和 Windows 库属于原生依赖，“全 Rust”不要求重写这些依赖。`rust/ui-lab` 名称沿用原型时期，现已是默认生产前端。

生产默认已从早期 **WGC 游戏窗口捕获**改为 **DXGI 主屏采集 + GDI 回退**，避免黄框并恢复旧版默认路径。WGC 自有窗口工具仍用于诊断，不是需要重新接回的生产目标。历史函数名如 `tick_wgc` 不能用来判定实际后端。

## 8. 性能与最新验证证据

- 等级门禁的 3 / 7 / 11 / 15 是阈值，不是领取计数。当前快速探测间隔 250 ms、普通兜底 1500 ms、省电 8000 ms；进入阈值 / 接近阈值和死亡 / 复活的加速窗口有 20 秒上限，画面证据另有有限保留。**调度间隔不是承诺的 OCR FPS**。
- 屏幕证据至少两次确认后才进入识别；明确消失与不确定遮挡采用不同关闭宽限。复用标题与结果、持久 worker、按需图标、后台数据 / 战绩任务都已接入。没有每帧 PNG 编解码或新增整屏哈希。
- 缺等级或画面证据时保守回退；不因固定处于某级而无限高速 OCR。一局“分析次数”仍不能直接等同模型推理次数或弹窗出现次数。
- 日志最多 3 × 256 KiB，重复状态合并、后台批量写入；自动报告有固定字段 / 长度 / 队列上限。当前没有全帧录制、完整崩溃转储或长期 GPU 历史分析产品。
