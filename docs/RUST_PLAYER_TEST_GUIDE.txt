FUZE Rust 中文阶段测试说明

安装与启动
1. 把整个 ZIP 复制到另一台 Windows x64 电脑，完整解压到可写目录。
2. 退出其他 FUZE/ARAMGG 助手，避免两套识别同时运行。游戏由你正常操作。
3. 本次验证优先双击 Start-this-build.cmd，直接启动当前解压包的版本，无需安装。
4. Start-preview.cmd 和开始菜单可能启动此前已安装的版本，不用于确认本次修复。需要安装时再使用 Install-local.cmd，不覆盖 Electron 稳定版。
5. 点击右上角 X，选择“退出软件”或“最小化”，也可以取消。最小化继续后台运行；开启“最小化时收入托盘”且托盘可用时收入托盘，否则保留在任务栏。

先在大厅确认：战绩、设置能一次点击打开，首页显示“通信已验证”。任何一项失败就停止，不必进入对局。
连接失败请只抄首页原因和 LCU- 开头的固定错误码，不发送账号、临时密码或原始日志。
基础检查通过后建议测试 2 局；若第一局无法连接、完全不识别、持续掉帧或抢焦点，直接退出并反馈，不必凑局数。
第一局正常玩，观察自动连接、我方五人/候选更新、三卡名称和顺序、出现后的等待、赛后清理。
第二局正常玩，留意自然发生的刷新、遮挡、碎片或锻造器场景；没有遇到就注明未测试，不必刻意购买或改变游戏操作。
当前自动推荐继续使用整体胜率，实际领取轮次未确认；金色推荐框不代表按当前轮次排序。
三张卡下方分别显示第 1–4 次的胜率参考；点卡片可查看对应场次和说明。
不足 200 场显示“少样本”，缺失显示“—”；来源、补丁、数据日期和补丁差异会标明。
阶段数据在选人/加载时准备，对局中仅读缓存。中途启动或准备失败时可能暂无缓存，不能据此判定 OCR 故障。
这次重点确认第一轮三卡能否识别、后续轮次是否持续工作，以及刷新/遮挡时左右卡位是否正确；不需要你手动确认领取轮次。
截图恢复 v0.6.3 的默认主显示器采集策略：持久流使用 DXGI，避免 WGC 的黄色捕获指示框；异常时自动用位图回退，冷却后重试。无需手动填写 Game 目录来启动屏幕采集。
采集只在已连接且受支持的对局阶段运行，退出对局或暂停后停止；图像只在内存中处理，不保存屏幕截图。

赛后如何给反馈
0. 运行日志会自动脱敏保存。设置页“运行状态与反馈”显示日志是否正常；可打开日志目录，写入失败时可重试。
   退出前也可暂停识别并“导出脱敏反馈”，包含本次内存状态、已保存日志和手动检查过的领取字段结构。
   只有手动领取检查快照仍需退出前导出；连接、截图、OCR 日志退出后可以补导。
   新增可选的“GitHub 自动反馈”：配置仅 ye602a/fuze-assistant Issues 读写权限的独立令牌，再开启每局自动上传。令牌保存在本机 Windows 凭据管理器，不随测试包分发。
   开启后每局赛后上传脱敏摘要；首次明确识别故障提前上传，赛后更新同一份报告。设置页显示待传数量和最近报告编号；失败保留队列，未配置令牌时使用下方手动导出。
1. 正常退出 FUZE，等待约 5 秒，让识别观察摘要完成保存。
2. 在本解压目录双击 Export-feedback.cmd。无需管理员权限或额外依赖。
3. 目录会生成一个 Fuze-feedback-xxxxxxxx.json。只把这个 JSON 拖进 Codex 聊天附件。
4. 同时写：测试了几局、是否自动连接、是否手动选择过游戏目录、识别等待大约多久、哪里出错。
   建议格式：第 1 局/第 2 局；发生在选人/加载/第几次三卡/刷新/赛后；现象；大概本地时间。
   如有错误码，手动抄下；窗口截图请裁掉账号、好友列表、聊天和其他个人信息。

导出的是什么
这是本地手动生成的脱敏反馈，包含最近最多 5 个识别片段摘要，以及最近 3 个轮转日志文件。
日志记录启动/正常关闭、连接/阶段/截图流/OCR 状态、等级门禁、固定错误类别、三卡可读位置和定期识别耗时。
新增 capture_source 区分 screen-stream（持久屏幕流）、screen-bitmap（位图回退）；capture_fallback 仅记录固定回退原因，不包含屏幕内容或窗口名称。
overlay_prepared 仅表示已准备浮窗数据，不能证明窗口已在屏幕显示。
日志位于 %LOCALAPPDATA%/FuzeRustPreview/logs，每个最多 256 KB，总计最多 768 KB；轮转只替换这套日志自己的三个文件。
重复状态合并，识别指标最多约每 10 秒汇总；后台约 2 秒批量写入，正常退出会收尾，强制终止可能丢失尾部缓冲。
片段数不等于对局数，事件次数不等于领取次数，平均完成耗时不等于卡片弹出后的等待时间。
不导出账号/账号摘要、区服、gameId、英雄/符文 ID、绝对时间、路径、令牌、密码、设置或截图；不上传任何内容。
导出脚本仅在双击时运行，不增加对局中的采集和后台轮询。

若显示 missing-observations 或 segments 为 0，请仍发送生成的 JSON，并写明“没有识别成功”或对应现象。
没有观察记录不能证明没有发生故障。即使未连接或从未识别成功，仍可退出后运行 Export-feedback.cmd 导出已有日志。
日志状态 missing 表示没有这版日志，partial 表示个别行/文件损坏或不可读，不能当作“没有故障”。观察摘要损坏也不会阻止导出日志。
本版复用已有助手 CPU/内存采样，不额外采样游戏进程，不记录原始接口响应或每帧图像；不要发送整个数据目录。
如果导出工具失败，先退出 FUZE 再重试；仍失败只反馈工具提示，不发送原始缓存。

隐私与兼容边界
不要打包 %LOCALAPPDATA%/FuzeRustPreview，也不要发送 observations-v2.json、账号战绩缓存、preferences 或凭据。
本包为未签名 Rust 阶段预览，不代表完整迁移验收或正式稳定发布。保留原稳定版，仓库仍私有。
需要 Windows x64、系统支持的图形捕获和 Visual C++ x64 运行库；若系统报告缺少 VCRUNTIME140.dll，请记录错误，不要从随机网站下载 DLL。
本次只面向简体中文常用窗口环境，多语言不属于开发目标；跨屏、远程桌面、独占全屏按实际情况注明未测试。
