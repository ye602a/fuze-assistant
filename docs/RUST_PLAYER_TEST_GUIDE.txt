FUZE Rust 中文阶段测试说明

安装与启动
1. 把整个 ZIP 复制到另一台 Windows x64 电脑，完整解压到可写目录。
2. 退出其他 FUZE/ARAMGG 助手，避免两套识别同时运行。游戏由你正常操作。
3. 本次验证优先双击 Start-this-build.cmd，直接启动当前解压包的版本，无需安装。
4. Start-preview.cmd 和开始菜单可能启动此前已安装的版本，不用于确认本次修复。需要安装时再使用 Install-local.cmd，不覆盖 Electron 稳定版。
5. 窗口关闭按钮通常收起到托盘；结束测试请使用退出按钮或托盘“退出”。

先在大厅确认：战绩、设置能一次点击打开，首页显示“通信已验证”。任何一项失败就停止，不必进入对局。
连接失败请只抄首页原因和 LCU- 开头的固定错误码，不发送账号、临时密码或原始日志。
基础检查通过后建议测试 2 局；若第一局无法连接、完全不识别、持续掉帧或抢焦点，直接退出并反馈，不必凑局数。
第一局正常玩，观察自动连接、我方五人/候选更新、三卡名称和顺序、出现后的等待、赛后清理。
第二局正常玩，留意自然发生的刷新、遮挡、碎片或锻造器场景；没有遇到就注明未测试，不必刻意购买或改变游戏操作。
当前自动推荐继续使用整体胜率，实际领取轮次未确认；分阶段统计只是手动参考。

赛后如何给反馈
1. 正常退出 FUZE，等待约 5 秒，让识别观察摘要完成保存。
2. 在本解压目录双击 Export-feedback.cmd。无需管理员权限或额外依赖。
3. 目录会生成一个 Fuze-feedback-xxxxxxxx.json。只把这个 JSON 拖进 Codex 聊天附件。
4. 同时写：测试了几局、是否自动连接、是否手动选择过游戏目录、识别等待大约多久、哪里出错。
   建议格式：第 1 局/第 2 局；发生在选人/加载/第几次三卡/刷新/赛后；现象；大概本地时间。
   如有错误码，手动抄下；窗口截图请裁掉账号、好友列表、聊天和其他个人信息。

导出的是什么
这是本地手动生成的脱敏识别摘要，不是旧 Electron 版的完整日志。
只包含最近最多 5 个识别片段的次数、完成识别的平均耗时、缺失卡位、等级与事件类型。
片段数不等于对局数，事件次数不等于领取次数，平均完成耗时不等于卡片弹出后的等待时间。
不导出账号/账号摘要、区服、gameId、英雄/符文 ID、绝对时间、路径、令牌、密码、设置或截图；不上传任何内容。
导出脚本仅在双击时运行，不增加对局中的采集和后台轮询。

若显示 missing-observations 或 segments 为 0，请仍发送生成的 JSON，并写明“没有识别成功”或对应现象。
没有观察记录不能证明没有发生故障。此版本尚无持久化连接/截图失败日志或 CPU/GPU 采样报告，相关问题需要你描述状态文字和时间；不要发送整个数据目录。
如果导出工具失败，先退出 FUZE 再重试；仍失败只反馈工具提示，不发送原始缓存。

隐私与兼容边界
不要打包 %LOCALAPPDATA%/FuzeRustPreview，也不要发送 observations-v2.json、账号战绩缓存、preferences 或凭据。
本包为未签名 Rust 阶段预览，不代表完整迁移验收或正式稳定发布。保留原稳定版，仓库仍私有。
需要 Windows x64、系统支持的图形捕获和 Visual C++ x64 运行库；若系统报告缺少 VCRUNTIME140.dll，请记录错误，不要从随机网站下载 DLL。
本次重点是简体中文常用窗口环境；跨屏、远程桌面、独占全屏及其他语言按实际情况注明未测试。
