# Rust 中文首测：范围、证据与剩余交付

2026-10-16 重新收敛目标。审查的业务代码基于 `a02ef539325577cf75fb748d68492814b23a59ea`（PR #66）；本批仅修正阶段构建入口和验收文档，不改业务及 UI 布局。

## 判定

**中文核心功能已适合进入受控实战测试阶段；当前还没有本批同一源码构建并通过整包检查的玩家交付物，所以暂不让玩家运行零散 EXE 或旧测试包。** 下一步只完成一次同版本阶段构建、载荷检查和隔离安装/回滚，生成一个测试包；失败只修复直接阻断项。不再把全量多语言、所有显示环境或真实游戏表现预先验证作为首测前提。

首测通过不等于完整 v0.6.3 一致性、长期稳定或正式发布通过。既有稳定版保留，仓库继续私有，不在本批合并堆叠 PR、发布 Release、安装或启动真实游戏宿主。

## 原目标与偏离

| 项目 | 判断与处理 |
|---|---|
| 技术与产品方向 | 保持 Rust 服务、Slint + Skia 中文主界面/英雄详情、Direct2D + DirectWrite 三卡；未切回 Electron。旧实现用于对照及稳定版保留 |
| 中文结构 | 保持左侧导航、大状态、四模块、三卡和原美术；五人阵容 + 候选网格是用户已确认的差异，不能再列为待确认 |
| 首测门槛 | 近期更新网络、多语言及图形环境补查挤占了首测交付。将这些完整迁移项目与中文首测分开；实战本身不能作为允许开始实战的前置条件 |
| 阶段打包入口 | 原 Rust 工作流默认 Win32 且未构建 Slint，可能交付错误界面。本批增加阶段前端选择，默认 Slint，从同一次 checkout 构建后才组包；显式选择 Win32 仅用于对照 |
| 发布入口 | `release-windows.yml` 仍服务既有 Electron 稳定版；不得通过打 `v*` 标签冒充 Rust 发布。Rust 首测走显式阶段验收，不改稳定版发布路线 |
| 领取轮次 | 仍未知，继续整体胜率。等级、刷新、碎片和锻造器不推断领取；手动阶段参考不等于自动推荐已使用阶段统计 |

## 首测前仅剩的交付门槛

1. 在确定的提交上构建 Rust 宿主、OCR worker、updater 和 **release + GPU feature Slint**，不混入历史本机 EXE。Windows 阶段工作流使用 `stage_acceptance=true`、`ui_frontend=slint`；只在需要一个可下载测试包时选择 `artifacts=preview`。普通 PR 和默认工作流执行均不打包。
2. 使用白名单公共模型、运行库和数据组装；确认 `build.json.uiFrontend=slint`、载荷自检、受管启动、隔离安装与失败回滚、隐私检查成功。不能只凭 CI 成功或 ZIP 存在就放行。
3. 只交付这一个阶段测试包，给出确定的启动入口/版本及退出恢复方法。保留稳定安装，真实游戏由玩家操作。若无直接阻断问题，不再添加功能或扩大验证矩阵。

本批没有执行阶段工作流、生成 ZIP/安装器、替换稳定版或启动在线宿主。修改后的阶段工作流完整云端构建仍待执行。

## 玩家首局只验证这些

拿到明确放行的同版本包后再开始，建议先用通常的分辨率/窗口模式和简体中文；玩家自行避免两个助手同时识别。

1. 大厅：连接是否经过 API 验证，状态是否对应当前阶段；自动目录发现失败要记录失败类型，手动回退成功不能当作自动发现成功。
2. 选人：顶部我方五人、候选网格是否跟随变化，英雄详情是否更新且不抢输入焦点。
3. 强化选择：三卡顺序和中文名称是否对应、出现后是否及时；遮挡位置有占位提示；刷新期间旧结果有标记，替换后不残留错误英雄/卡片。
4. 正常遇到碎片或锻造器时观察即可，不为凑覆盖额外操作；它们不得增加实际领取轮次，推荐仍标为整体胜率。
5. 赛后与退出：旧三卡清除，暂停能停止识别，退出能结束自有 worker；战绩失败有说明且保留缓存。只反馈现象、时间和耗时，不需上传原始日志或账号。

明显持续掉帧、窗口抢焦点、错误结果持续不清除、暂停无法停止时，由玩家退出测试版并继续使用保留的稳定版；后续只处理此次反馈的阻断问题。

## 后移，不能继续阻挡中文首测

- Slint 完整英文/繁中文案和语言入口：仍未完成，属于全量迁移。
- 所有输入法、多屏混合 DPI、RDP 切换、独占全屏、真实驱动重置：按玩家实际环境逐步验收，不要求首局覆盖所有组合。
- 私有网络单次下载稳定性、新 Slint 版本真实线上升级：单独记录；已有真实差分、续传与历史资产校验不等于新包升级成功，也不必为首测重复优化网络。
- 真正领取轮次确认、自动阶段统计：没有可靠信号继续关闭，不能靠推测补齐。
- 仓库公开、正式替代稳定版、完整迁移结项：仍需完整验收与发布审查。
