# 符择 Fuze 0.5.0 · 本地战绩、识别摘要与存储管理

本次正式版整合 PR #2–#5：在线服务不可用时保留已保存战绩，记录对局中观察到的三卡，赛后查看识别摘要，并提供按需缓存清理。

## 战绩与复盘

- 自动从当前客户端解析国服区服；在线接口失败后尝试客户端近期记录。已保存战绩按账号、区服隔离，断开客户端后可离线查看，界面标明数据来源。
- 选人和游戏中不主动请求远程战绩；观察到对局结束后尝试补充一次，不持续重试。
- 勾选「仅查看本地已保存战绩」后，按英雄、胜负或重开筛选全部已保存记录，再分页显示。每个账号与区服组合最多保存 500 场。
- 修复离线记录读取期间客户端连接的边界，避免继续返回之前账号的三卡记录。

## 本地三卡与识别摘要

- 保存接受的左右三卡、缺失位置、观察时间、等级与选项变化，在线战绩服务失败时仍能查看。
- 仅在账号、区服和对局 ID 对应时关联赛后强化；「赛后拥有」不代表在某次画面中选择，也不推断真实重选次数。
- 确认归属的对局即使没有三卡结果，结束时也保存识别摘要。展开一局可查看截图、分析、等级等待、实际 CPU/GPU 推理请求、GPU 回退、推荐匹配、浮窗事件与最近异常环节。
- 零次识别不直接判为故障，事件发送不保证窗口实际可见，计数不是 CPU/GPU 利用率。旧对局无法补录，中途启动或重连可能留下缺口。

## 存储与运行稳定性

- 设置页新增「存储管理」，主动展开才扫描。先预览、再确认清理七天未修改的旧推荐版本与已知临时文件。
- 保留当前完整版本、一个完整回退版本及本次运行用过的数据；个人战绩、选择记录、配置、日志和诊断截图不在删除范围。
- 游戏或识别期间拒绝清理；预览过期、文件变化或目录链接会停止或跳过。
- 修复 OCR 销毁后旧任务重新启动、停止截图后旧推荐残留；限制推荐数据内存缓存，GPU 失败回退 CPU 与模型空闲释放保持可用。
- 摘要复用已有流程，没有新增截图、OCR、哈希、网络轮询或写盘定时器。

## 隐私与上传检查

个人战绩与三卡记录保存在本机，当前发行频道关闭遥测和后台战绩上传。GitHub 更新授权由每台电脑独立配置并加密保存，不随安装包分发。源码、开发提交历史与安装包在上传前检查凭据；规则发现问题会阻止发布。界面示例使用虚构数据。

## 安装

下载下方 **Fuze-Setup-0.5.0.exe**。仓库仍为私有，需要有权限的 GitHub 账号；已配置私有仓库只读授权的 Fuze 可在设置页检查、下载并确认安装。选人和对局中禁止安装，不启用静默自动更新。安装包尚无 Windows 发布者签名。

随包提供 `.blockmap`、`latest.yml` 和 `SHA256SUMS.txt`。本次发布不远程替换用户正在运行的程序，也不操作游戏或鼠标。

## 验证与已知边界

发布前通过 402 项单元测试、代码规范、类型检查、生产构建、真实 OCR 固定图片回归、源码/包内凭据扫描，以及真实打包程序窗口启动检查。旧缓存、多次启停、重连、迟到响应、账号切换和清理边界均有回归覆盖。

这些检查不等于国服整局实战验收，不承诺所有腾讯区服战绩接口恢复，也不承诺 CPU/GPU 占用降幅。当前推荐仍使用整体统计，分阶段胜率尚未接入。
