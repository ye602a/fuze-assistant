# 符择 Fuze 0.6.0 · 增量更新与选人体验修复

这次把私有频道增量下载、选人置顶、备选英雄刷新修复，以及分阶段数据的手动参考一起带到正式版。

## 更新更省下载量

- 有可用旧安装包缓存时，优先只下载变化部分，重建后校验完整安装包。
- 缓存缺失、差分文件异常或服务器不支持范围下载时，自动回退完整包。
- 进入选人或对局会取消下载，不因取消再启动整包下载；返回大厅后由你重新发起。
- 更新仍由你主动检查、下载和确认安装。不会退出时自动安装，也不会对局中热替换程序。

**从 v0.5.0 或更早版本首次升级，仍可能下载完整包。** 旧更新器不会提前获得新能力；安装本版本后，后续更新才使用新链路。节省比例取决于具体版本与本机缓存。

## 选人窗口更及时

- 默认开启“选人时置顶英雄详情”，减少被普通窗口盖住的情况，可在偏好设置中关闭。
- 进入游戏仍按原有隐藏设置执行，没有定时抢焦点。
- 修复旧推荐请求覆盖当前备选英雄的问题；真实阶段变化后恢复自动刷新。

## 阶段统计与诊断

- 支持分阶段胜率数据的本地缓存与手动参考。
- 增加手动检查实际领取信号的入口，仅返回限定字段和计数，不输出账号身份或原始响应。
- 实际领取轮次尚未可靠确认前，三卡仍使用整体统计，不按等级、弹窗次数或属性碎片猜测轮次。

## 隐私与性能

认证仅发送到本仓库的 GitHub API，每次重定向重新创建请求，资产服务器不接收认证、Cookie 或客户端标识。令牌由每台电脑单独配置并加密保存，不随安装包分发。

没有新增后台轮询、截图、OCR 或整文件预哈希。缺少旧安装包时跳过差分元数据请求；复用更新框架原有的完整性校验。个人战绩后台上传保持关闭。

## 安装

下载下方 **Fuze-Setup-0.6.0.exe**，或在已授权的私有频道检查更新。私有仓库需要访问权限。安装包尚无 Windows 发布者签名。

随包提供 `.blockmap`、`latest.yml` 和 `SHA256SUMS.txt`。发布检查包括单元测试、OCR 样例、差分取消与隐私回归、真实历史安装包下载重建、包内凭据扫描和实际打包窗口启动检查；这些不等同于国服整局实战验收。

不会自动操作游戏或鼠标。本次发布也不会自动替换你正在运行的程序。
