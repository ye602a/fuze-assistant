# 符择 Fuze 0.6.3 · 当前阶段稳定测试版

这一版收束当前开发阶段，供继续实战测试。后续开发路线可独立调整。

## 看得懂的运行状态

- 首页状态背景随真实状态变化：蓝色正常等待、绿色工作正常、黄色暂停/准备/兼容回退、红色异常。
- 客户端、游戏画面、中文识别、推荐数据四格分别说明是否正常以及正在等待什么。大厅待命不再被“待初始化”或上一局截图时间混淆。
- 推荐依据明确标出“整体胜率 · 正式领取轮次未确认”。

## 更清楚的选人参考

- 顶部固定五个我方位置，标记自己；未选位置保留空位。
- 下方仅展示公共备选池，按胜率从高到低排列，同时显示选取率。暂无胜率的英雄排在末尾。
- 队友英雄不会混入可直接选取的名单。列表仅供查看，不代替玩家操作。

## 识别与连接修复

- 语言提示在后台刷新，等级读取不再挡住截图；对局中保留 OCR 模型，停止识别后恢复空闲回收。
- 缩短候选画面的第二帧确认间隔，保留双帧确认和失败退避。
- 确认选择画面且两张标题可信时，缺失卡位保留位置并提示可能遮挡；短暂刷新动画保留宽限。
- 进程路径不可读时，增加有限注册表与快捷方式发现，并验证只读 LCU 响应。手动目录仍为最终回退。

## 更新说明

私有频道差分下载已实现；本版新增实际下载模式及回退原因提示。有可用旧安装包缓存时优先只下载变化部分，缺少基线或差分失败时下载完整包。无论哪种方式都需校验，安装仍由玩家确认，选人及对局期间禁止安装。

首次安装或从旧版手动覆盖，不保证下一次一定能增量。增量节省的是下载量，不是游戏中热更新。

## 仍需实战验证

本版没有开启自动分阶段推荐。等级、刷新、属性碎片、锻造器及候选出现次数均不能证明正式领取轮次。分阶段数据继续只供手动参考。

新识别链路的对局延迟、特殊额外选择以及不同国服安装环境，仍需要玩家实战反馈；测试通过不等于所有机器均已验证。

下载 `Fuze-Setup-0.6.3.exe`；其余 blockmap、更新清单和校验文件用于更新与完整性验证。源代码 ZIP 不是安装包。
