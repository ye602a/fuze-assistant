# 符择 Fuze 0.4.1 · 海克斯三卡与轻量识别

这次更新聚焦对局中的可读性、识别链路的重复开销，以及开发依赖安全。

## 三卡更清楚

- 深蓝底、金属金边与青蓝高亮；优先推荐使用金色边框。
- 移除卡片序号、顶部序号与版本统计标签。
- 左侧图标扩大至 66–76 像素，右侧选取率与胜率扩大至 21–25 像素。
- 推荐度条由 2 像素加粗到 9 像素；缺失数据和长标题不会撑坏布局。
- 保留游戏左、中、右顺序与局部重选逻辑。

## 减少重复工作

- 在截图进程内逐像素过滤完全相同的帧，减少整帧传输，移除主进程中的重复哈希。
- 合并同时到达的预热请求；相同配置下，后台预热最多每 30 秒尝试一次。实际识别仍按需初始化。
- OCR 连续闲置两分钟后释放模型进程，下次识别时重新初始化；GPU 失败后仍可回退 CPU。
- 保留等级门禁、特殊触发低频探测、原始像素复用与分析背压。

合成 120 帧微基准中，静态画面待传像素减少 99.2%，每十帧变化一次时减少 90%，每帧变化时不减少传输。这是受控数据验证，不是游戏内 CPU 或 FPS 的提升承诺。

## 依赖与发布

- 依赖审计从 11 项降至 0 项：升级 Vue 与文件匹配依赖，替换打包下载工具的旧依赖链。
- 移除没有源码引用的直接依赖 `lodash-es`、`nanoid`；保留构建工具仍需的间接依赖。
- 更新 GitHub 项目说明与原创矢量 banner。

## 安装与测试

下载 `Fuze-Setup-0.4.1.exe`；已有 0.4.0 的用户可通过设置页的私有更新频道检查、下载，退出对局后确认安装。私有更新需要本机读取授权。当前安装包没有 Windows 发布者签名，不进行静默安装。

本地检查覆盖单元测试、构建、OCR 固定样本、真实打包窗口、GPU/CPU 与 GPU 退出后的回退。完整记录见 [依赖与性能检查](https://github.com/ye602a/fuze-assistant/blob/v0.4.1/docs/FUZE_041_REVIEW.md)。真实国服对局、远程桌面、多显示器与不同显卡仍需玩家测试。
