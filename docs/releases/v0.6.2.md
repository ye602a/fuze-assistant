# 符择 Fuze 0.6.2 · 海克斯主界面与领取轮次验证

主界面现在与符文弹窗采用一致的深蓝、黄铜金和青色状态提示，更新原创应用标志及图标。当前状态和本局三卡优先展示，调度、数据来源等详细信息可折叠，窄窗口也能使用。

## 领取轮次：可观察，尚未自动判定

偏好设置的“领取轮次验证”支持操作前后对照，包含正式选择、刷新、属性碎片、锻造器连续选择、额外选择和重连等验证场景。

**实际领取轮次仍未确认，三卡推荐继续使用整体胜率。** 手动场景标签、等级、弹窗次数、字段或事件数量变化都不会推进正式领取轮次。分阶段胜率仍供手动参考。

会话变化、接口失败、观察超过两分钟时拒绝对照；清空之后迟到的结果不会恢复旧记录。

## 如何实战验证

1. 在安全方便时进入“偏好设置 → 领取轮次验证”，选择正在验证的场景，点击“检查一次”。
2. 可用时点击“记为操作前”，自行完成一次选择或刷新。
3. 等待检查间隔满足后再次“检查一次”，查看前后变化。两份观察须处于同一会话且相隔不超过两分钟；检查有 30 秒冷却。
4. 分别验证正式选择、刷新、属性碎片和连续锻造器，尤其留意碎片先于正式等级奖励弹出的情况。没有候选字段或无法对照也是有效结果，不等于 OCR 故障。

这些观察用于寻找可靠信号，不会自动操作游戏。建议反馈界面中的状态和脱敏计数即可，无需提供账号、令牌或原始接口响应。

## 隐私与性能

仅手动读取固定本地接口，最多在当前页面内存保留两份脱敏观察，不写盘或上传。使用已有连接状态隔离会话，没有新增后台轮询、截图或 OCR。界面使用静态矢量图标，没有新增动画循环。

延续 0.6.1 的私有频道增量更新、选人置顶和备选英雄刷新修复。增量下载需要可用旧安装包缓存，否则下载完整安装包；更新仍由玩家手动确认。

下载 **Fuze-Setup-0.6.2.exe**，或在已配置访问权限的私有频道检查更新。安装包尚无 Windows 发布者签名。请在退出对局后自行安装。
