# 符择 Fuze 0.4.2 · 选择流程修复与标题缓存

本次更新修复连续选择与迟到推荐的边界问题，并减少相同标题的重复 OCR。

## 选择流程

- 属性碎片和无法确认的选择界面不再消耗正式强化次数，避免真正强化稍后出现时提前进入节能检测。
- 正式强化“属性！”等仍正常识别；碎片只做保守分类，不提供属性选择建议。
- 静止画面被去重后，仍推进选择框消失计时，无需重复分析图片。
- 旧推荐带有选择序号，关闭后即使再次出现相同卡片，也不会接收上一轮迟到的窗口或数据结果。
- OCR 异常回退为未知状态；对局阶段不允许识别时阻止迟到弹窗。

## 减少重复工作

- 背景变化、标题未变时，复用最近一组三个标题的识别结果，跳过重复拼图、指纹与 OCR。
- 普通完整结果最多复用 3 秒，明确碎片标题最多 10 秒；标题变化立即失效，不会暂停画面变化检查。
- 缓存像素上限 2 MiB。截图链路不新增逐帧密码学哈希。

## 数据说明

- 胜率优先使用自身的来源、地区和版本字段，避免误用外层的腾讯国服标记。
- 当前仍使用整体统计；分阶段胜率与 ARAMKit 数据尚未接入。

## 安装与验证

下载下方 `Fuze-Setup-0.4.2.exe`。已有 Fuze 的用户可通过设置页检查私有 GitHub 更新；每台电脑需要独立的仓库读取授权。退出对局后再安装。安装包尚无 Windows 发布者签名，不启用静默安装。

发布流程要求单元测试、代码规范、类型检查、OCR 固定样本，以及真实打包窗口检查通过后才上传安装包。真实国服碎片画面、连续锻造器、多显示器与远程桌面仍需要实战验收。离线缓存耗时不是游戏内 CPU 或 FPS 提升承诺。
