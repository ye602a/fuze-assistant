# Rust 预览版与完整迁移的明确差异

更新：2026-10-17。本轮以 `v0.6.3 / 58aea5ee649c531220bed20db6307ff12dfad90c` 为功能基线，以 PR #75 及其后续源码为当前实现。**源码已实现、测试包已包含、玩家实测正常是三个不同结论。** 本报告没有重新运行历史安装包，没有检查或替换玩家安装；不能把本轮源码改动说成已经在此前测试包生效。

## 范围与核实方法

从 v0.6.3 的 `src/renderer/main.js` 四条生产路由反查 `Display`、`MatchHistoryPanel/AugmentJournalPanel`、`AugmentWinrateOverlay` 和 `AugmentFloatingOverlay`，再对照 preload、主进程实际门禁、Rust 服务及 Slint 回调。也核对迁移 PLAN、PROGRESS、V063_PARITY、逐控件账本与交付/私有下载报告。没有只凭“文件存在”就把旧组件算成玩家功能。

历史原型按阶段保留：Win32/GDI、Slint 软件/Skia 实验不是另一套需要继续同步完善的产品；生产方向为 Rust 服务 + Slint/Skia 主界面、选人与侧栏 + Direct2D/DirectWrite 三卡。旧 Electron 稳定版仍保留。已有测试的证据沿用原报告，本轮只验证变动路径。

## 安装、更新与公开的差异

| 项目 | 预览现状 | 完整迁移/正式交付仍需什么 |
|---|---|---|
| 载荷 | 独立 ZIP/本地安装脚本，包含原生二进制、模型、数据；本地和 CI 默认均为 Slint，旧 Win32 仅显式选择；需要 x64 VC++ 运行库 | 签名安装器/引导程序、运行库依赖处理与最终同版本安装验收；不是“换个预览名称就正式” |
| 数据目录 | `%LOCALAPPDATA%/FuzeRustPreview`，保留稳定版独立数据 | 是否切换正式目录及旧安装交接需最终发布决定；不能默默覆盖稳定数据 |
| 差分更新 | 已有 `.fuz` + 自有 `.blockmap` + `rust-update.json`；失败整包、断点续传、版本切换与回滚 | **不是没实现**。与 Electron `latest.yml`/NSIS blockmap 不兼容；旧 Electron 不会直接差分变成 Rust。历史私有资产差分/续传验证不等于最新 Slint 包完整在线升级通过 |
| 私有授权 | Windows 凭据管理器，手动设置/移除；不嵌入令牌 | 当前仓库私有继续需要授权。完整迁移后公开及公共频道切换另做；不提前公开 |
| 发布信任 | 白名单 HTTPS、散列、清单校验 | 散列不等于发布者签名；正式签名与信任策略仍未完成 |
| 卸载/回滚 | 独立受管目录、健康检查、回滚、快捷方式/已安装应用登记已有实现 | 最新最终载荷整链、真实系统操作验收。保留个人文件/未知文件属设计；旧 Electron 安装保留，不自动卸载 |
| PR/Release | 堆叠分支逐项 CI；日常 PR 不生成玩家安装包 | 最终依赖顺序合并、一个阶段包、玩家实战，然后决定稳定替换；公开前还须代码历史/Actions/资产/许可证审查 |

## 上一批：后台战绩读取

- 修复战绩读取要求暂停的交互退化。后台只启动一个有界读取任务，并与赛后刷新共用队列；识别/监控保持原状态，暂停/退出不受读取任务阻塞。
- 读取期间阻止重复请求、导入/清理/设置事务抢占；完成前保留列表；普通通信失败保留明确标记的旧缓存，账号/登录/区服冲突不沿用旧账号结果。
- “更多战绩”根据真实游标可用性启用；显示来源，缓存错误时明确未重新验证当前账号。没有新增自动战绩轮询。
- 对照报告清除多语言、日志与禁用旧功能造成的伪欠项；历史阶段报告只保留历史证据，不再当当前任务列表。

定向库测试：9项通过，覆盖后台完成/互斥/阶段变化、保持识别模式、暂停退出、缓存隐私与选择性导入。正常优化的 Slint GPU/审查构建通过；612项双尺寸组件检查0失败（含重复尺寸、禁用状态，不是独立按钮数）；隐藏宿主服务通过，已查看原生战绩页渲染。本地证据保留在忽略目录 `rust/ui-lab/artifacts/parity-history-controls` 和 `parity-history-host`。审查构建不作为发布包。所有数据为合成夹具，没有读取玩家记录、调用游戏接口、模拟系统输入或安装/重启 FUZE。

## 本批：剩余显示差异与冗余清理

- 战绩恢复每页10局；只转换当前页的显示时间，使用 Windows 本机时区及历史夏令时规则。缓存和导出仍保存原始 UTC 时间戳，不修改系统时区，不增加后台轮询。转换失败时带 UTC 标记，不把失败伪装成本地时间。
- 删除手写公历日期换算，改用 Windows 时间 API；删除 Slint 中无控件使用的语言切换属性、回调及宿主重复赋值。中文 UI 不再保留虚假切换接口，OCR 自动语言识别、数据语言隔离和旧设置兼容仍保留。
- 本地打包脚本默认值从旧 Win32 对齐到当前 Slint；缺少 Slint 二进制会失败，不静默退回旧界面。显式 `FUZE_UI_FRONTEND=win32` 继续供历史对照使用，旧载荷的运行时兼容规则不变。
- 包内 README 删除重复英文前言与过期入口/未完成描述；测试、日志与反馈步骤统一引用 `TESTING-zh-CN.txt`。本批只修改生成规则，没有生成新包。
- 清理边界：逐项检查 Slint 属性/回调引用和打包入口。旧 Win32 仍有命令行对照、安装健康检查及历史包兼容用途；原型探针仍被 CI 引用。它们不是仅凭“旧”就可删除的代码。历史验收报告保留证据并指向当前差异，不作为第二套待办；稳定版源码、已有安装包及用户本地文档没有删除。

本批验证：战绩定向库测试12项通过，覆盖正负时区、跨日/闰日、夏令时两个边界和转换失败；Slint 优化审查构建通过；隐藏宿主服务通过，第一页10条/第二页2条、过滤恢复、详情清理正常。已查看原生战绩详情和第二页图像，合成时间由00:00 UTC显示为08:00本地，布局与日期文字正常。打包脚本语法和1091个文件的隐私扫描通过。产物在忽略目录 `rust/ui-lab/artifacts/history-cleanup-host`，没有上传图像或运行日志。实际系统文件选择、跨屏/焦点、真实游戏与最终安装升级的验收范围不因这些定向检查缩小。

## 当前结论

仍是预览候选，**没有通过完整迁移放行**。源码缺口、实际未测与正式发布工作已经分开；不要继续以“还差多语言/日志/自动装备”无限扩展开发。下一阶段应验收最终同版本程序的真实窗口/对局和更新链，再根据实际阻断修复。可靠领取信号继续作为独立研究条件，保持整体推荐不妨碍中文版核心功能测试。
