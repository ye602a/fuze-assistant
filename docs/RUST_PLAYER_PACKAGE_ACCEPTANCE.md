## 反馈方式及边界

见 [玩家中文说明](RUST_PLAYER_TEST_GUIDE.txt)。建议正常玩两局，第一局出现阻断故障可立即停止。退出 FUZE 后，双击包内 `Export-feedback.cmd`，手动发送生成的 `Fuze-feedback-xxxxxxxx.json` 并描述状态文字、错误码及现象。

工具仅在玩家显式运行时读取最多 2 MiB 本地 observations-v2.json，重新构造白名单摘要，不原样导出文件。只保留最近五个片段的完成识别计数/平均耗时、事件类型、等级、可读槽位；去除账号摘要、区服、gameId、英雄/符文 ID、绝对时间和路径。最多五片段不等于五局，观察不等于领取，平均完成耗时不等于弹窗延迟。没有记录仍输出 missing-observations，不能据此判定链路正常。

此版本没有持久化连接/截图失败日志或 CPU/GPU 采样报告，相关问题需要玩家同时提供界面状态与现象；不要求上传原始数据目录。导出工具无网络、无对局轮询、不启用额外运行日志。

本次未发布 Releases、未合并堆叠 PR、未公开仓库。实际领取轮次未确认，推荐继续整体胜率；完整迁移、其他语言与全部显示环境验收仍未完成。
