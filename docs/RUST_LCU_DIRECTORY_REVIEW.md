## 连接与隐私边界

- 手动回退仍需 Toolhelp 发现当前 LeagueClient / LeagueClientUx；不把磁盘旧文件当成当前客户端。
- 路径可读取时，候选必须属于填写的安装目录；多个无法区分的同类客户端不猜测。
- 优先保留仅含 SYNCHRONIZE 权限的进程句柄；无法取得句柄时，以进程名、PID、父 PID 的快照检查存活。快照不能提供内核句柄级别的 PID 重用保证，因此该路径每次轮询重新发现凭据并重新认证，不跨轮询缓存成功状态。
- 请求成功且游戏阶段有效才发布连接状态；401、404、超时、未知阶段仍按失败处理。
- 日志每目录最多枚举 4096 项，只读最新三个匹配 PID 的文件，每个最多 256 KiB；读取在后台发现链路，不在 OCR / UI 线程。
- 认证内容只在本地内存处理，临时缓冲区擦除；没有增加路径、端口、认证 URL、账号或原始日志输出。
