## 启动与退出

使用本轮已编译的 `fuze-ui-lab.exe`，不需要安装包。在普通 PowerShell 中运行（以下相对路径以本目录为起点；配置过 CARGO_TARGET_DIR 时换成对应的实际编译输出路径）：

```powershell
./target/release/fuze-ui-lab.exe --manual-profile skia "$env:TEMP/FuzeUiManual/skia"
```

检查完点击原型窗口自己的关闭按钮。关闭时写入 `manual-skia.json`，仅记录请求后端、实际观察到的图形 API/显卡名称、耗时及事件计数。**不记录中文输入内容、按键、鼠标位置、账号、路径、窗口截图**。没有上传功能；非正常终止可能不生成报告。

如需对照 Skia 软件备选，关闭上一个原型后运行：

```powershell
./target/release/fuze-ui-lab.exe --manual-profile skia-software "$env:TEMP/FuzeUiManual/skia-software"
```

标题下显示的是“请求后端”。是否实际启用 OpenGL 以报告 `observed_graphics` 为准；该字段为空表示没有观察到，不等于 GPU 成功。软件路径没有 OpenGL 回调是正常现象，不能把回调数为零当成窗口不绘制。

## 如何反馈

告诉我测试后端、Windows 缩放档位、输入法名称、哪项通过/失败即可。故障描述例如：“150% 副屏，微软拼音候选框停在主屏，输入文字本身正确”。可提供生成的计数报告；无需发送账号或游戏画面。

## 迁移放行条件

- 中文输入、实际使用的 DPI/窗口恢复场景通过；没有条件的高风险项目保持未验证，不能以自动检查替代。
