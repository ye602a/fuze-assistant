# 私有全量下载：减少重复跳转与分段耗时

2026-10-16，基于 PR #63；该前置 Windows CI 38905418434 已复核成功。继续保留稳定安装和私有仓库，不生成新安装包，不执行安装或访问游戏。

## 已确认的问题与实现

原先完整包分块每次从 GitHub asset API 开始，再获得 CDN 重定向。现在首块串行探测在严格状态码、Content-Range、长度检查通过后，仅在本次 `archive_observed` 调用中复用最终地址；四路后续请求直接访问这个地址。缓存由调用拥有，下载结束即释放，不写入配置、日志或磁盘，不跨包复用。

凭据仍仅发往固定仓库 API；CDN 始终不带 GitHub 令牌，不允许重定向回 API。目标域名/协议检查、最多四跳、每块范围/长度、整包最终校验、四路 1 MiB 上限、整体十分钟预算及取消边界继续保留。地址过期或拒绝访问时终止，不增加重新认证或自动重试循环。

原先四块必须整批全部完成才写入并启动下一批。现在按顺序等待和写入一块后立即补上下一个请求，保持最多四个在途/已完成块和四个 IO 工作线程，减少快速请求等待同批慢请求的空档。发生错误后不再补任务，仍回收所有在途线程；权限等终止错误优先于普通网络错误，防止错误分类触发不该有的全量回退。

开发诊断新增每个请求的固定角色、等待响应头耗时、响应头之后耗时和正文字节数。验证脚本只汇总数字，不记录下载地址、响应内容或认证信息。响应头耗时包含句柄准备、DNS/TLS、请求及服务器等待；正文阶段还包含本地写入和资源释放。并行请求的耗时之和不是总耗时，也不能当作 CPU 时间。统计包括元数据和重定向请求；包下载字节仍使用原有独立计数。

## 连接复用调查

不能从每次创建 WinHTTP session 直接推断每次都重新进行 TCP/TLS 建连：WinHTTP 默认支持匿名连接跨 session 池化。本批不另造句柄池、不添加 unsafe 跨线程句柄共享，也不盲目增加连接数。微软文档说明默认每服务器连接上限为无限，而不是常见的浏览器两连接假设。

依据：[WinHTTP 功能与连接池](https://learn.microsoft.com/en-us/windows/win32/winhttp/about-winhttp)、[选项：连接池和连接上限](https://learn.microsoft.com/en-us/windows/win32/winhttp/option-flags)、[WinHTTP 并发与句柄生命周期](https://learn.microsoft.com/en-us/windows/win32/winhttp/concurrency-in-winhttp)。这些说明支持实现边界，不证明当前网络的瓶颈来自连接建立。

## 真实网络分步结果

只含地址复用、仍用旧批次调度的构建：差分 3 个范围、995,461 字节重建 48,200,101 字节，最终校验通过；全量写入 34,603,008 字节后触发共同十分钟预算，未通过。

这一轮合计 API 请求尝试 7 次、CDN 请求尝试 42 次；API 响应头累计 6,879 ms、CDN 响应头累计 14,676 ms，响应头之后累计 1,544,805 ms。后者明显占主导，不能把主要耗时解释成重复 API 跳转、DNS 或认证；它也不能进一步证明是哪家网络或服务器限速。并行累计耗时不等于墙钟耗时，不把这一轮的快慢波动作为严格性能对照。

最终构建（地址复用 + 滚动调度）的复验：差分仍为 3 个范围、995,461 字节，重建最终校验通过；从开始到差分完成为 33,310 ms。全量有序写入 22,020,096 字节（21 MiB）后失败，固定诊断为 `available / 12002`，即 `WinHttpQueryDataAvailable` 等待正文数据超时；错误归类为 `update-cancelled-or-timeout`，没有整体预算截止诊断。全量最终校验未完成，**真实全量下载仍未通过**。

最终构建合计 API 请求尝试 7 次、CDN 请求尝试 30 次；API 响应头累计 5,836 ms、CDN 响应头累计 11,588 ms，响应头之后累计 1,235,463 ms。统计正文写入 26,307,031 字节包括元数据、差分和并行中未提交到整包的缓冲，不能等同已完成包大小。两次联网测试不构成控制变量性能基准，不能声称新版实际速度提升，也不能单凭本次超时断言调度变更导致变慢。

本批不再反复下载整包、不放宽接收或总体超时。后续重点是网络路径和正文收包可靠性，而不是重复修改哈希或盲目增加线程；必要时再设计用户显式选择的网络路径/失败续传。认证隔离、取消、最终校验必须保持，完整在线升级仍不放行。
