# Slint 运行收口与集中开发侧验收

2026-10-16，基于 PR #57。PR #57 的 Windows CI（38879586045）已复核成功。本批继续分支与 PR，不合并、不发布、不替换稳定安装。当前会话继续，整个移植完成且功能稳定后才换会话。

## 实现与故障修复

- Slint 已拥有三卡窗口时，宿主管线使用纯上下文门禁，不再创建旧隐藏 Win32 浮窗、UI 线程或等待窗口 ACK。保留取消、数据版本、generation 和 sequence 检查。旧 Win32 独立启动路径不变。
- 设置页移除没有本地日志服务支撑的无效按钮，改为返回首页运行状态。领取验证接上显式检查、操作前基线和清除；30 秒冷却、单个在途任务、对局上下文变化清理。只显示本地接口的固定状态、字段数量、等级和对比计数，不存储或上传原始响应。离线模式在调用接口之前拒绝操作。
- 检查不确认实际领取；等级、弹窗、刷新、碎片、锻造器与观察次数仍不能推动阶段。自动推荐保持整体胜率。此轮未调用真实游戏接口。
- 不可操作的语言下拉框改为明确显示“简体中文 / 其他界面语言仍在迁移中”，保留已保存的数据语言；不假称全语言迁移完成。
- 测试载荷支持显式 `FUZE_UI_FRONTEND=slint`，包含 Slint EXE 和 `uiFrontend` 标记，同时验证公开数据/OCR 运行依赖与迁移目录后的 Slint 启动。默认 Win32 保持兼容。输出目录已存在则拒绝，避免混入旧载荷。
- 更新验收基线改版本号时保留前端标记；启动故障注入针对真实选中的前端。修复此前可能验证旧 Win32 而未验证 Slint 的问题。
- 隔离安装检查首次遇到 `install-launch-readiness`；单独排查得到 `desktop-smoke-foreground`。旧断言把其他应用前台变化也算作抢焦点。改为在启动 tick 和退出时检测本进程是否拥有前台，仍验证自有窗口隐藏；只报告外部前台是否变化，不查询身份或恢复焦点。该采样不代替可见窗口焦点验证。

## 复现隔离载荷检查

先完成 Rust 宿主、worker、updater、验证器与 Slint 功能构建。使用新的输出目录：

```powershell
$env:FUZE_UI_FRONTEND = 'slint'
$env:FUZE_RUST_BIN_DIR = '<isolated release binaries>'
$env:FUZE_RUST_PREVIEW_DIR = '<new ignored validation output>'
node scripts/package-rust-preview.mjs
node scripts/package-rust-update.mjs
fuze-update-verify.exe --offline <rust-update.json> <archive.fuz> <baseline directory> <new isolated install root>
```

这里的 ZIP/FUZ 是安装回滚夹具，不是玩家发布包；不运行 Install-local.cmd，不注册已安装应用，不写开始菜单真实目录。基线与目标可以使用同一构建，验证器只在隔离副本内生成较早版本身份；因此不能声称验证了真实历史跨版本差分或 GitHub 私有下载。

## 尚不能宣称完成的部分

- 最新分支的完整 Windows CI 要以最新提交结果为准；PR #57 的成功不能替代本批。
- Slint 自动 GPU 降级/设备恢复没有本轮证明；本轮隐藏启动使用 Skia 软件后端。
- 全量多语言和语言激活事务未完成。简体中文首测范围与全功能迁移分别记录。
- 可见窗口的中文 IME、拖动、跨屏、独占全屏、系统托盘交互和真实对局 CPU/GPU/延迟，必须在玩家开始测试后验证；本轮不干预用户桌面或游戏。
- 没有读取私有频道令牌，也没有向 GitHub 发起真实更新下载；离线分块/回退和安装生命周期不等于该网络链路成功。
- 尚未把这份功能验证构建发布为首个实战安装包。完整迁移稳定与换会话的条件仍未达成。
