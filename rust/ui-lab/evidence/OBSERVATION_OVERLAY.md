# 未绑定完整观察与三卡说明、拖动、位置记忆

基于 PR #56（Windows 编译 CI 已通过）继续。此批按用户要求执行必要编译、格式、差异、隐私检查；统一运行验收推迟。没有运行窗口、游戏接口、截图/OCR、真实记录读取或安装器，不以编译证明实战可靠。

## 本批完成的接线

- 战绩页原“未绑定本地观察”入口增加完整事件展开。最近 8 段，每段保留既有最多 80 次；每页显示 5 次，三个卡位分别显示名称和缺失提示。时间保留至毫秒并标注 UTC，等级和事件类型分别显示。旧记录缺少事件元数据时只显示已有卡片，不补造时间、等级或重新出现事件。
- 英雄和强化名称从既有公开中文数据读取，后台按需准备，每次数据版本最多准备一次，失败可收起再打开重试。缺失名称保留编号并说明。新版本到来丢弃旧名称结果。没有上传本机事件，也没有猜测账号归属。
- 宿主提供不含账号摘要、区服或对局编号的观察快照，只在事件/记录段/结束标志变化后重建。空闲 UI 轮询比较共享快照，不重复克隆完整历史或读取个人文件。事件更新时收起详情，避免原来的列表下标指向另一段记录。
- Direct2D 三卡点击展开当前卡片说明，再点收起；滚轮与“上移/下移”均可阅读长说明，缺说明有明确反馈。说明使用已有数据中的纯文本，不解析网页。刷新保留结果继续标记为旧结果，新卡组/管线上下文会收起旧说明，推荐仍使用整体胜率。
- 标题栏使用 Windows 自有窗口的拖动命中区，关闭与卡片区域保留各自操作。继续使用不激活、工具窗口和置顶样式；不注入输入、不移动游戏窗口。
- 复用窗口记忆服务，生产会话保存 `FuzeRustPreview/window-direct-cards.json`；移动完成后由现有 UI tick 提交后台写入，退出也提交最终位置。保存收起时尺寸；说明展开高度不进入记忆。显示器/DPI变化按当前工作区重新约束位置与尺寸，窄工作区同步缩放绘制与点击坐标。保存失败提示，下次移动重试。离线入口不读取/写入真实位置。

## 当前验证与边界

本机 `cargo check --features gpu --locked --offline -j 1` 已退出 0，编译 Rust、Slint 与 Windows API 接线，未执行这些 API。格式与差异检查通过。Impeccable 机械扫描返回空结果，但不是 Slint/Direct2D 原生渲染验证，不能证明布局、焦点、中文输入或跨屏行为。上传前继续核对暂存内容及隐私检查；远端以本批 PR 最新提交的 CI 为准。

统一验收需要覆盖：旧记录无元数据、未知编号、部分卡位、80 次分页、账号绑定隔离、新记录插入和版本切换；三卡长说明、缺说明、滚动边界、刷新与卡组切换、关闭后不反复弹出；100–200% DPI、负坐标显示器、移除副屏、保存失败、可见窗口不抢焦点与关闭/重启后的恢复。只用合成数据先做开发侧检查，再由用户实战确认。
