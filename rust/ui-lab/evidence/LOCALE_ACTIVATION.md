# 语言数据切换：先验证、再保存、最后发布

2026-10-16，基于 PR #60。保持现有中文界面、稳定安装与整体胜率推荐，不生成安装包。

## 本批修复

- 显式切换数据语言时，宿主原先仅验证符文和英雄列表；现在在保存设置之前检查完整目标语言数据，包括装备、英雄分片索引及所引用分片。
- 拒绝“新版不完整缓存供 OCR 使用、旧版完整内置数据供详情使用”的混合激活。完整数据与 OCR 的版本、来源必须一致。
- 目标数据不完整或设置原子保存失败时，不提交新偏好或宿主配置，不停止旧识别控制器。
- 成功重建识别控制器后，一次性清除旧选人、局内英雄、三卡、连接验证及时间，等待新会话状态，避免新语言搭配旧结果。
- 完整检查只在显式语言偏好变化时执行；普通界面设置不重新读取数据，不增加逐帧校验或哈希。自动语言仍由已有客户端流程决定。

## 边界与剩余工作
