# 私有频道跨进程续传验证

2026-10-16，基于 PR #65。先复核 Windows 更新 CI 38910612712，结果成功。本批不打安装包，不安装或启动下载包，不访问游戏、LCU、账号缓存或玩家日志。

## 验证入口

开发验证器新增两个互相独立的入口：先从真实私有发布资产下载 1 MiB 并主动中断，再由另一个进程重新获取认证和发布信息，打开同一隔离缓存续传。第二步仍执行生产 `Session::archive_from_observed`、`Cache::transfer` 和最终完整包 SHA-512 校验。

只有第一步允许新建目录；第二步要求已存在的验证标记，重新比对完整清单，发布内容改变则拒绝。每次输出独立报告，不覆盖旧报告，不把历史文件长度伪造成已验证内容。原本的差分/强制全量验证入口保留。

运行形式：`node scripts/check-rust-private-transfer.mjs <verifier> <existing-baseline.fuz> <new-private-transfer-directory> resume-seed`，完成后将最后参数改为 `resume`，使用同一个目录。已有基线参数保留为脚本接口兼容要求，续传模式不读取或复制其内容。凭据仍仅通过匿名管道传入；报告仅包含固定错误、字节、耗时、计数及公开版本标识。

## 收包改动

完整响应改用固定 64 KiB 缓冲直接调用 `WinHttpReadData`，移除逐次 `WinHttpQueryDataAvailable`。微软文档说明，完整下载直接读取能省去额外缓冲复制，而查询可读量通常不超过 8 KiB。此处只据此减少 API 调用，不把理论开销减少说成真实带宽提升或已定位网络故障。

参考：[WinHttpQueryDataAvailable](https://learn.microsoft.com/en-us/windows/win32/api/winhttp/nf-winhttp-winhttpquerydataavailable)、[WinHttpReadData](https://learn.microsoft.com/en-us/windows/win32/api/winhttp/nf-winhttp-winhttpreaddata)。

仍检查 HTTP 状态、Content-Range、响应尺寸和完整哈希；每次读取前后检查取消/预算。短读继续，只有成功返回零字节才代表正文结束；多一个字节也拒绝超限。没有放宽 TLS、认证主机、代理策略、并发或超时设置。同步系统调用返回之前不能即时响应取消，这一限制仍然存在。

## 本批证据

目标为已发布的历史资产 `adaae7937cdd`，48,200,101 字节，并非本批 Slint 安装包。测试目录为仓库忽略的 `rust/artifacts/private-transfer-20261016-resume`；不提交下载包、缓存、认证信息或原始网络输出。

| 步骤 | 结果 |
|---|---|
| 旧收包实现，真实下载后主动中断 | 保留 1,048,576 字节，33,593 ms；未执行整包校验 |
| 旧收包实现，第二进程从 1 MiB 续传 | 603,361 ms 后返回 `update-cancelled-or-timeout`，缓存保留 36,700,160 字节（35 MiB）；本次接收 39,039,104 字节，含有序写入失败后丢弃的并行缓冲；整包未校验 |
| 新收包实现，第三进程从 35 MiB 续传 | 成功；213,150 ms，仅接收剩余 11,499,941 字节，完整 48,200,101 字节包的 SHA-512 校验通过；随后缓存载荷归零 |

最后一步 3 次 API 请求、12 次 CDN 请求（含清单）；API 响应头累计 2,064 ms，CDN 响应头累计 6,427 ms，响应头后累计 531,996 ms。并行累计时间不是墙钟耗时或 CPU 时间。固定网络错误与预算诊断均为空，过程退出码 0。保留量与请求起点都是 36,700,160 字节，接收量恰好等于完整包减去此前保留量；不是从零全量重下或由旧完整包复制出来的通过。

真实失败恢复链路已通过。本次不同进程处理了不同字节区间，也经历不同网络条件，不构成收包改动的控制变量性能基准，不能证明网络根因消失或量化速度提升。第一次恢复依然在约 603 秒失败，不能声称单次完整下载已稳定完成。

定向检查：4 项续传边界测试通过；2 项收包测试通过，包含新增短读、EOF、范围不足、超限及读取前后取消检查。最终更新器与开发验证器均已在隔离 Windows 工具链编译链接，验证脚本语法检查通过。未重复 UI 大规模渲染验收或生成安装器。

## 验收边界

下载并通过完整哈希，只证明真实发布资产的传输/缓存/校验链路；不证明新 Slint 包在线安装、回滚或游戏场景通过。完整 UI 语言入口、可见 IME/跨屏及首次实战仍按阶段交接清单推进，不在本批通过反复打包替代这些验证。
