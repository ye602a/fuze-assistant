# 2026-10-16 原型证据

Windows 本机、Rust 1.90、release、`gpu` 特性构建。图片为原型自身绘制的固定样例，不含游戏截图、账号、日志或用户输入。下面的数字不代表整个 FUZE 的内存/CPU/GPU 或游戏掉帧改善。

## 同一主界面：预热后的光栅化快照

| 请求后端 | 样本数 | 中位数 | P95 | 12 次进程 CPU 时间 |
|---|---:|---:|---:|---:|
| Slint software | 12 | 153.15 ms | 221.03 ms | 1765.63 ms |
| Slint Skia | 12 | 2.94 ms | 5.43 ms | 46.88 ms |

两次分别启动进程，显示同一 1120×860 工作台，先快照预热，再循环四种状态各三次。计时不含 PNG 编码；样本含快照分配、布局和光栅绘制，**不是 GPU 帧耗时，也不是 OCR 耗时**。源记录为相邻 JSON 文件。两种原生 Winit 窗口都保持隐藏，观察到前台窗口未变。

建议继续评估 Skia 为主窗口首选后端。当前 software 路径已暴露明显绘制成本，不能凭“全 Rust”判定性能达标；需要进一步定位字体/布局与光栅路径，不能直接当成轻量默认后端发布。Skia 的真实可见绘制、实际 GPU、软件降级仍未验收。

这些是小样本、本机结果，DPI 档位间不是单调关系，不作线性外推。浮窗面积和文字少于主界面，不用此表比较 Slint 与 Direct2D 的快慢。

隐藏 HWND 的硬件目标成功创建，NOACTIVATE/TOOLWINDOW/TOPMOST 样式通过，观察到前台未变；主动释放重建资源成功。约 812 ms 检查中 0 次空闲绘制，进程 CPU 增量低于采样分辨率。隐藏目标可能跳过被遮蔽的绘制，其提交时间不作为性能通过依据；本次未模拟设备故障。
