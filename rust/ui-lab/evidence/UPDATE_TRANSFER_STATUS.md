# 更新下载状态与终止边界

2026-10-16，基于 PR #59。保持稳定版、中文版主界面结构和整体胜率推荐；本批没有生成或发布安装包。

## 已完成

- 差分失败只对可恢复原因回退全量一次。取消、WinHTTP 超时、授权/重定向策略异常以及本地写入/散列服务错误直接终止；旧版和原文件保留。旧基线损坏或块图无效仍允许一次完整下载。
- 块图、差分和全量共用十分钟下载预算。不会在每次全量回退时重新计算总时间；校验沿用原有取消检查。同步网络请求仍需等待当前 WinHTTP 调用返回，界面如实显示“等待当前请求结束”，不宣称即时取消。
- 更新窗口区分差分、无基线全量、差分失败后的全量、最终校验。显示完整包大小、预计复用量、已接收包数据量。计数包含失败尝试，不含块图、HTTP/TLS 开销；它不是系统网卡流量，也不是虚构的完成百分比。回退后清零预计复用，保留已接收计数。
- 字节计数发生在网络接收写入边界；每次缓冲区写入一次原子加法。沿用更新器已有的低频状态循环，仅快照改变时更新文字。没有新增游戏循环、截图、轮询线程或重复文件散列。
- 用户取消后，不再继续询问是否安装，也不再额外弹出取消错误框。已发起的安装指针切换沿用既有原子事务边界。
- 更新模式不再直接显示 `delta/full`；新增文案具有简中、繁中、英文对应项。只增加更新进度窗口的文字高度，保留既有操作和布局结构。
