# 自动语言上下文与观察名称一致性

2026-10-16，基于 PR #61。保留中文版主界面与五人阵容、候选英雄网格结构；不生成安装包，不替换稳定版。

## 修复范围

- 原先选人目录只在新语言非空时重置，语言从已知变为未知时可能继续构造旧语言的英雄视图。现在将目录、重试期限和选人快照放在同一个宿主对象中；未知语言清除旧目录及视图，恢复语言后重新准备。
- 自动语言只接受当前连接且未过期的监测结果。断连、暂停、超过已有 8 秒时效或探测结果为空时，不向选人数据层继续提供旧语言。显式语言偏好依然优先。
- 旧原生浮窗在自动语言模式下曾把文字语言回退成简体中文；现在使用实际已准备的数据语言。Slint 主界面的完整翻译入口仍未开放。
- 未绑定观察名称不再固定读取简体中文，也不再忽略实际加载的数据版本。它必须匹配宿主声明的语言与版本，失败时保留编号和卡位，不混用名称，更不把观察顺序当成领取轮次。
- 名称加载只需要符文和英雄列表，移除无关装备文件依赖；后台单任务、按需加载、过期回复拦截保持不变。选人数据失败沿用 30 秒重试；正常 tick 和暂停恢复复用内存目录，不增加逐帧文件校验。
- 主界面的推荐数据版本仍表示可用本地数据；连接断开不会把缓存本身误报为不存在。

## 验证范围

- 合成目录的 `locale_context`：3 项通过，覆盖过期/断连语言、已知→未知→恢复、数据更新后的同阵容刷新、失败退避和三种语言的精确名称版本。
- 原有 `locale_activation`：4 项通过，复核设置提交与失败保留未受影响。
- Slint GPU 功能编译检查通过；本地功能二进制用于隐藏自有窗口检查，不作为安装包或发布性能证据。
- 本批新构建二进制 `--review-host` 通过，包含真实宿主设置/暂停/选人刷新、维护确认、记录分页及新增名称身份清理。`closure-review.json` 确认未知/变化版本清除旧名称，保留编号与卡位。人工检查生成的自有隐藏窗口图，等待提示及编号无新截断；未抓取桌面或游戏。
- 隐藏检查报告：`foreground_unchanged=true`、`game_access=false`、`personal_data_read=false`、`system_input=false`。这不替代可见窗口、中文输入法或实战验证。
- PR #61 Windows CI 38899584011 已复核成功；本批 CI 在新的堆叠 PR 中运行定向语言检查与一次隐藏宿主检查，不重复整套图形/安装器测试。
